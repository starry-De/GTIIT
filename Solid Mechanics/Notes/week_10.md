# 🌟 结构力学/材料力学核心笔记：超静定问题求解指南

**超静定问题 (Statically Indeterminate Problems)** 的本质是：未知的约束反力数量 > 独立的静力平衡方程数量，必须结合**变形相容条件**和**物理本构关系**才能求解 [cite: 8, 89, 90, 91]。

应对考试，你需要熟练掌握两套截然相反的“破局”剑法：**力法**与**位移法**。

---

## 🗡️ 第一剑：力法 (Force Method)

**核心思想**：把多余的**力**当做未知数。先拆约束，再算位移，最后用位移相容条件把力求出来 [cite: 93, 94]。

### 📝 考试标准解题流程 (4步法)

1. **确定超静定次数，解除多余约束 (建立基本系统)**
   * **动作**：拿掉结构中多余的支座或约束，使其变成一个可以自由变形的**静定结构**。
   * **定义**：被拿掉的约束反力，就是你的基本未知数（假设为 $R_1$, $R_2$ 等）。

2. **计算“外力”单独作用下的位移 ($\Delta_0$)**
   * **动作**：在这个静定结构上，只施加题目给定的真实外力（如 $P$、温度变化 $\delta T$）。
   * **计算**：求出刚才“去掉约束”的那个点，在外力作用下产生的自由位移 $\Delta_0$。
   * *提示：注意规定位移的正负号方向。*

3. **计算“多余未知力”单独作用下的位移 ($\Delta_1$)**
   * **动作**：撤掉所有外力，只在这个静定结构上施加未知的多余约束力（如 $R_1$）。
   * **计算**：算出在该点产生的位移 $\Delta_1$。此时位移表达式中必定包含未知数 $R_1$ 以及柔度系数 $f$（$f = \frac{L}{EA}$）。

4. **建立变形相容方程，求解未知力**
   * **动作**：强行让两者位移抵消（因为现实中那个点是固定死的，总位移必然为0）。
   * **方程**：$$\Delta_0 + \Delta_1 = 0$$
   * **收尾**：解方程求出 $R_1$。最后利用整体静力平衡方程（如 $\sum F_y = 0$）求出其他剩下的支座反力。

## 🛡️ 第二剑：位移法 (Displacement Method)

**核心思想**：把节点的**位移**当做未知数。先假设节点动了，算各杆件产生的弹力，最后用节点受力平衡把位移求出来 [cite: 95]。

### 📝 考试标准解题流程 (4步法)

1. **识别受力节点，设定未知位移**
   * **动作**：找出结构中可以在外力作用下移动的“活动节点”。
   * **定义**：假设该节点产生了一个未知的位移量 $\Delta$（明确设定正方向，通常设受力方向为正）。

2. **利用物理方程(刚度)，用位移表达内力**
   * **动作**：把每一段杆件看作弹簧，根据节点的位移 $\Delta$，判断每一段杆件是“被拉长”还是“被压短”。
   * **计算**：根据刚度 $K = \frac{EA}{L}$，计算各段杆件的内力。
     * 公式：$$F_{内} = K \cdot \Delta_{形变}$$
   * *注意：要弄清形变方向，杆件被拉长则产生拉力，被压短则产生推力。*

3. **对节点建立静力平衡方程，求解位移**
   * **动作**：以该活动节点为研究对象（画隔离体受力图）。
   * **方程**：该节点受到外部施加的外力 $P$，以及周围各杆件对它施加的拉/推力。
     * 公式：$$\sum F_{节点} = P + F_{杆1} + F_{杆2} + \dots = 0$$
   * **收尾**：将第2步的内力表达式代入，解出一个只包含未知数 $\Delta$ 的方程，求出真实的位移量。

4. **回代求内力与反力**
   * **动作**：把求出的真实位移 $\Delta$ 代回第2步的公式中，直接得出各段杆件的真实内力。
   * **收尾**：根据内力推导两端支座的最终反力。

## ⚖️ 终极对比速查表

| 对比维度 | 力法 (Force Method) | 位移法 (Displacement Method) |
| :--- | :--- | :--- |
| **求解的“基本未知数”** | **未知的约束力** (如支座反力 $R$) | **未知的节点位移** (如节点下沉量 $\Delta$) |
| **列方程的核心依据** | **几何相容条件** (如: 墙壁处位移和必须为0) | **静力平衡条件** (如: 节点处各力之和必须为0) |
| **核心物理参数** | **柔度** $f = \frac{L}{EA}$ | **刚度** $K = \frac{EA}{L}$ |
| **解题直觉** | “拆墙放开变形 $\rightarrow$ 用力压回原位” | “假设节点移动 $\rightarrow$ 弹簧受力去硬刚外力” |
| **考场适用场景** | 约束多、节点少的情况 | 节点多、结构复杂的情况（有限元软件底层逻辑） |

> **💡 考场避坑指南：** > 无论选哪种方法，**必须在草稿纸上画出明确的坐标系和正负号方向！** > 力法容易死在“方向抵消”上（$\Delta_0$ 和 $\Delta_1$ 是同向还是反向），位移法容易死在“受拉还是受压”的判定上。**符号不错，分就稳了！**
