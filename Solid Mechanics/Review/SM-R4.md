第四周的课程进入了静力学的进阶应用阶段。前半部分我们将刚体平衡扩展到包含多力构件的**框架与机械**；后半部分我们打破了“光滑表面”的假设，引入了真实的**干摩擦**分析。

以下是第四周核心知识点、定理与例题的全面整合：

---

### 第一部分：框架与机械 (Frames and Machines)

**1. 核心定义与区别**
* **多力构件 (Multi-force Member)**：承受三个或以上的作用力，或承受两个以上的力及一个力偶的构件 。
* **框架与机械的判断**：只要结构中包含**至少一个多力构件**，就属于框架或机械 。
* **区别**：框架通常用于在静态条件下支撑载荷；机械通常涉及运动部件，用于传递和转换力与力矩 。

**2. 结构分类与解题策略**
* **刚性/不可折叠结构 (Rigid Non-collapsible)**：
    * 特征：移除外部支撑后，结构依然保持为一个坚固的整体 。
    * 策略：**先整体，后局部**。先对整个结构画受力图 (FBD) 求出外部反力，然后再拆解求内力 。
* **非刚性/可折叠结构 (Non-rigid Collapsible)**：
    * 特征：移除外部支撑后，结构会松散变形 。
    * 策略：**先局部，后整体**（或边局部边整体）。必须先将结构拆解，通过分析各部件来求解内部反力和外部反力 。

**3. 牛顿第三定律与作用力表示**
* 在拆解结构画隔离体受力图 (FBD) 时，连接处的相互作用力必须成对出现（大小相等、方向相反）。
* 如果在部件 A 上假设受力向右 ($A_x$)，在相连的部件 B 上就必须画成向左 ($-A_x$) 。

### 第二部分：干摩擦 (Dry Friction) 基础与摩擦角

**1. 干摩擦特性与库仑定律**
当两粗糙表面有相对滑动趋势时，会产生切向的摩擦力 $F$ 和法向的支持力 $N$ 。
* **静摩擦阶段 (Static Friction)**：无相对滑动，$F < F_{max}$。此时摩擦力大小由平衡方程决定，与法向力无关 。
* **临界滑动状态 (Impending Motion)**：即将发生滑动，$F = F_{max} = \mu_s N$ ($\mu_s$ 为静摩擦系数) 。
* **动摩擦阶段 (Kinetic Friction)**：正在滑动，$F = F_k = \mu_k N$ ($\mu_k$ 为动摩擦系数，通常 $\mu_k < \mu_s$) 。

**2. 摩擦角 (Friction Angle)**
* 合力 $R$（摩擦力 $F$ 与法向力 $N$ 的矢量和）与法向 $N$ 的最大夹角称为摩擦角。
* **静摩擦角**：$\tan \phi_s = \mu_s$ 。
* **动摩擦角**：$\tan \phi_k = \mu_k$ 。
* 以法线为轴，摩擦角为半角旋转一周形成的圆锥称为**摩擦锥 (Friction Cone)** 。只要接触力 $R$ 落在静摩擦锥内部，物体就不会滑动。

**3. 三类摩擦问题的解题法**
* **Type I (已知即将滑动)**：处于临界状态，直接使用 $F = \mu_s N$ 结合平衡方程求解 。
* **Type II (已知正在滑动)**：处于动摩擦状态，直接使用 $F = \mu_k N$ 。
* **Type III (未知状态，需核验)**（**考试重点**）：
    1.  先**假设物体处于静止平衡状态** 。
    2.  利用平衡方程 $\Sigma F=0, \Sigma M=0$ 求出维持平衡所需的摩擦力 $F$ 和法向力 $N$ 。
    3.  **校验假设**：计算最大静摩擦力 $F_{max} = \mu_s N$ 。
        * 若 $F \le F_{max}$，假设成立，物体静止，真实摩擦力就是计算出的 $F$ 。
        * 若 $F > F_{max}$，假设不成立，物体正在滑动，真实摩擦力为 $F_k = \mu_k N$ 。

### 第三部分：楔块与自锁 (Wedges & Self-Locking)

**1. 楔块 (Wedge)**
* 依靠摩擦力工作，用于微调位置或产生极大的推力 。

**2. 自锁定理完整推导 (Self-Locking Theorem)**
* **问题**：当撤去推力 $P$ 时，楔块是否会因为上方载荷的挤压而自动滑出？
* **推导 (单侧受压情况)**：假设楔块上表面与水平面夹角为 $\alpha$（楔角）。要使楔块不滑出，上方接触面和下方接触面必须同时产生摩擦力阻止其向外滑动 。
* 考察上方接触面，支持力 $N$ 与摩擦力 $F$ 的合力为 $R$。当发生临界向外滑动时，$R$ 与接触面法线的夹角为静摩擦角 $\phi$ 。
* 从几何关系看（如课件图示），要保持静止，必须满足楔角 $\alpha$ 小于等于摩擦角 $\phi$。即：$\alpha < \phi$ 时，系统具有**自锁性**，不论法向压力多大，楔块都不会被挤出 。

### 第四部分：核心例题详细解析

#### 1. Sample Problem 4/7 (非刚性框架的拆解分析)
**题目**：一个 A 字形支架，左侧垂直杆 AB 在顶部受向右 30 lb 的力，右侧斜杆 CD 在末端受平行于杆向下的 50 lb 力。忽略自重，求各构件受力 。
**解析**：
* **判断结构**：A 和 C 为销轴固定，移除支撑后 A 字架会垮塌，属于非刚性结构 。
* **寻找二力构件**：杆 EF 两端为销轴且中间无受力，是典型的**二力构件**，受力方向仅沿 E 到 F 的连线 。
* **先求外部垂直反力**：将支架视作整体，对 C 点取矩消除 $C_x, C_y$ 和 $A_x$。$\Sigma M_C = 0 \rightarrow 50 \times 12 + 30 \times 40 - A_y \times 30 = 0$，解得 $A_y = 60$ lb 。$\Sigma F_y = 0$ 解得 $C_y = 100$ lb 。
* **拆解求内力**：隔离杆 ED，设二力杆作用力为 E。对 D 点取矩 $\Sigma M_D = 0 \rightarrow 50 \times 12 - E \times 12 = 0 \rightarrow E = 50$ lb 。再依次对杆 AB 和 BC 列平衡方程解出所有受力 。

#### 2. Sample Problem 6/1 (斜面摩擦角测定)
**题目**：质量为 $m$ 的物块放在可调倾角的斜面上，求物块开始滑动前的最大倾角 $\theta$ 。
**解析**：
* 受力分析：重力 $mg$ 向下，支持力 $N$ 垂直斜面向上，摩擦力 $F$ 沿斜面向上 。
* 建立沿斜面(x)和垂直斜面(y)的坐标系。
* $\Sigma F_x = 0 \rightarrow mg \sin\theta - F = 0 \rightarrow F = mg \sin\theta$ 。
* $\Sigma F_y = 0 \rightarrow N - mg \cos\theta = 0 \rightarrow N = mg \cos\theta$ 。
* 临界状态：$F = F_{max} = \mu_s N$ 。
* 代入方程：$mg \sin\theta = \mu_s (mg \cos\theta) \rightarrow \tan\theta_{max} = \mu_s \rightarrow \theta_{max} = \tan^{-1}\mu_s$。这个角也叫休止角 (Angle of repose) 。

#### 3. Sample Problem 6/5 (多接触面联动分析)
**题目**：30kg, 50kg, 40kg 三个物块叠放在 $30^\circ$ 斜面上，50kg 物块受拉力 $P$，30kg 物块被绳子固定。求不发生滑动的最大拉力 $P$ 。
**解析**：这是一个典型的“假设-检验”多接触面问题。
* 接触面 1 (30kg与50kg之间)：$\mu_s = 0.30$ 。
* 接触面 2 (50kg与40kg之间)：$\mu_s = 0.40$ 。
* 接触面 3 (40kg与斜面之间)：$\mu_s = 0.45$ 。
* **计算法向力 N**：沿垂直斜面方向列方程，$N_1 = 30g \cos 30^\circ$, $N_2 = (30+50)g \cos 30^\circ$, $N_3 = (30+50+40)g \cos 30^\circ$ 。
* **情景假设 A**：假设 50kg 的物块单独抽出（即接触面 1 和 2 达到极限，接触面 3 未达到极限）。此时 $P = F_1 + F_2 + 50g \sin 30^\circ$ ($F_1, F_2$ 代入最大静摩擦力) 。
* **情景假设 B**：假设 50kg 带着 40kg 一起向下滑动（即接触面 1 和 3 达到极限）。
* 计算并比较不同滑动模式下所需的 $P$ 值，较小的一个即为系统能够承受的最大拉力 $P$。
