### 第一部分：桁架基础与静定性分析 (Truss Basics & Determinacy)

**1. 简单桁架的假设条件**
*   **基本单元**：平面桁架的基础是三角形（最稳定的几何结构）。空间桁架的基础是四面体 (Tetrahedron)。
*   **理想化假设**：
    *   所有构件都是**二力构件 (Two-Force Members)**，只受拉力 (Tension) 或压力 (Compression)，受力方向沿两端连线。
    *   构件自重忽略不计。
    *   所有外部载荷仅作用在**节点 (Joints)** 上。
    *   节点被视为理想的**光滑销轴 (Pin)** (平面) 或 **球窝接头 (Ball-and-socket)** (空间)。

**2. 静定性判别公式 (Statical Determinacy)**
设 $m$ 为构件数 (members)，$j$ 为节点数 (joints)：
*   **平面桁架 (2D)**：
    *   $m + 3 = 2j$：内部静定 (Statically determinate)。
    *   $m + 3 > 2j$：超静定，含有多余构件 (Internal Redundancy)。
    *   $m + 3 < 2j$：结构不稳定 (Unstable)。
*   **空间桁架 (3D)**：
    *   判断公式为 $m + 6 = 3j$。

### 第二部分：节点法 (Method of Joints) & 零力杆的秒杀技巧

**1. 节点法核心思想**
*   隔离每一个节点，画受力图。每个节点处于共点力平衡状态。
*   **方程限制**：平面系统每个节点只能列 2 个方程 ($\Sigma F_x = 0, \Sigma F_y = 0$)，因此每次最多只能解 2 个未知力。空间系统每个节点列 3 个方程，最多解 3 个未知力。
*   **受力箭头画法**：永远把未知力的箭头画成**背离节点**（即假设为拉力 T）。如果算出来是正数，就是拉力；如果是负数，就是压力 C。

**2. 秒杀考点：判断零力杆 (Zero-Force Members)**
在没有外力或支撑反力作用的节点上：
*   **条件 1**：节点上只有两个不共线的构件 $\rightarrow$ 这两个构件都是零力杆。
*   **条件 2**：节点上有三个构件，其中两个共线 $\rightarrow$ 第三个不共线的构件是零力杆。
*(注：如果节点上有外力垂直于共线杆件，则第三根杆件受力等于该外力)*

### 第三部分：截面法 (Method of Sections)

**1. 截面法核心思想**
*   当你只需要求桁架中间某几根特定杆件的受力时，用节点法一步步推太慢，直接用假想的截面把桁架“切开”。
*   **方程优势**：隔离出桁架的一部分作为一个刚体，可以使用完整的三个平衡方程：$\Sigma F_x = 0, \Sigma F_y = 0, \Sigma M = 0$。
*   **切法限制**：一刀切下去，未知的被切断构件最好**不要超过 3 个**，否则方程不够解。
*   **解题技巧**：巧妙选择矩心（Moment centers）。如果切断了三根杆，找其中两根杆的作用线交点取矩，可以瞬间求出第三根杆的受力。

---

### 第四部分：空间桁架 (Space Trusses)

*   **节点法 (3D)**：每个节点建立 $\Sigma F_x = 0, \Sigma F_y = 0, \Sigma F_z = 0$。通常结合空间向量（单位向量、位置向量）进行计算，利用矢量方程 $\Sigma F = 0$ 和各项系数为零求解。
*   **截面法 (3D)**：不仅可以列 3 个力平衡方程，还可以列 3 个力矩平衡方程 ($\Sigma M_x = 0, \Sigma M_y = 0, \Sigma M_z = 0$)，理论上一个截面最多可以解出 6 个未知力。

### 第五部分：核心例题详细解析

#### 1. Sample Problem (截面法经典应用)
**题目**：计算悬臂桁架中 KL, CL, CB 杆的受力（G 点受向下 20 tons 载荷）。
**解析**：
*   **切一刀**：用一条虚线切断 KL, CL, CB 三根杆，取桁架左半部分作为研究对象。
*   **求 CB (找 KL 和 CL 的交点 L 取矩)**：
    *   L 点在 CB 的正上方，距离 CB 作用线高度差为 $21$ ft (通过比例 $16 + 5 = 21$ 算出)。
    *   $\Sigma M_L = 0 \rightarrow 20 \times 60 - CB \times 21 = 0 \rightarrow CB = 57.1$ tons (C，压力)。
*   **求 KL (找 CL 和 CB 的交点 C 取矩)**：
    *   $\Sigma M_C = 0 \rightarrow 20 \times 48 - (KL \cdot \cos\theta) \times 16 = 0$ (其中 $\cos\theta = 12/13$)。解得 $KL = 65$ tons (T，拉力)。
*   **求 CL (找 KL 和 CB 的交点 P 取矩)**：
    *   KL 和 CB 的延长线交于左侧 P 点。对 P 点取矩可消除 KL 和 CB 的力矩，直接求出 CL。计算得 $CL = 5.76$ tons (C，压力)。

#### 2. Sample Problem 4/5 (空间桁架节点法)
**题目**：三维四面体桁架，E 点受空间外力 $L$，求 E 点相连的各杆内力。
**解析**：
*   先将所有力向量化：算出 $F_{EB}, F_{EC}, F_{ED}$ 的单位方向向量。
*   在 E 点列矢量平衡方程：$\Sigma F = L + F_{EB} + F_{EC} + F_{ED} = 0$。
*   将所有力分解为 $i, j, k$ 分量，合并同类项，令 $i, j, k$ 的系数分别等于 0，得到三个标量方程。
*   解方程组得到：$F_{EB} = -L/\sqrt{2}$, $F_{EC} = -5L/6$, $F_{ED} = 5L/6$。

### 第六部分：期末冲刺自测题 (Practice Problems)

为了确保你能熟练应对考试，建议在草稿纸上尝试以下两道题的思路：

**题目 1：零力杆快速识别**
想象一个典型的屋顶桁架（比如 Pratt 或 Howe 结构）。
*   要求：不进行任何数值计算，仅依靠“零力杆的两个条件”，扫描整个桁架，圈出所有的零力杆。考试中，先剔除零力杆能让后续的节点法或截面法计算量减半。

**题目 2：截面法找矩心**
如果一个平面桁架被截面切断了上弦杆 AB、斜腹杆 BC、下弦杆 CD 三根杆。你现在孤立了桁架的左半部分。
*   要求：如果你想“一步到位”求出斜腹杆 BC 的内力，你应该选择哪个点作为矩心（Moment Center）来列力矩平衡方程？为什么？
*(提示：思考 AB 和 CD 这两根“不想求”的杆件的作用线延长线会交于何处)*
