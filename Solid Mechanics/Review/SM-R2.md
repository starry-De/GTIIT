这周的课程进入了静力学的核心：受力分析图（FBD）和刚体的平衡条件。掌握这些原则是解决所有静力学和后续固体力学问题的前提。

以下是为你整理的第二周重点知识、定理及例题：

---

### 第一部分：系统隔离与受力分析图 (System Isolation & FBD)

**1. 隔离系统与绘图步骤**
*   在应用平衡条件前，必须明确隔离要分析的物体或系统，绘制受力分析图（FBD）是力学解题中最重要的一步。
*   FBD 必须显示由于与其他物体接触而施加在系统上的所有外力，以及重力或磁力等体积力。
*   **构建步骤**：确定隔离系统 $\rightarrow$ 绘制完整外部边界 $\rightarrow$ 标出所有移除接触物体后产生的约束力、已知外力和体积力 $\rightarrow$ 建立并标出坐标系。

---

### 第二部分：支撑与反力模型 (Modeling of Forces)

**1. 二维系统 (2D) 中的约束与反力**
*   **柔性绳索/线缆**：始终产生沿绳索方向背离物体的拉力 $T$。
*   **光滑表面**：产生垂直于表面的压力 $N$。
*   **粗糙表面**：产生法向力 $N$ 和切向的摩擦力 $F$。
*   **滚子/滑块**：产生垂直于支撑面/导轨的法向力 $N$。
*   **光滑销轴 (Pin)**：支撑任意方向的力，通常分解为两个正交分量 $R_x$ 和 $R_y$。如果销轴不能自由转动，还会额外产生一个反力偶 $M$。
*   **固定端 (Fixed Support)**：提供两个正交力分量 $F$、$V$ 以及一个反抗旋转的力偶矩 $M$。
*   **弹簧**：线弹性弹簧受力为 $F = kx$；扭转弹簧受力矩为 $M = k_T \theta$。

**2. 三维系统 (3D) 中的约束与反力**
*   **光滑表面/球形支撑**：仅产生垂直于表面的法向力 $N$。
*   **球窝接头 (Ball-and-socket joint)**：允许绕中心自由旋转，提供三个空间力分量 $R_x, R_y, R_z$。
*   **固定连接 (Fixed connection)**：除了三个力分量 $R_x, R_y, R_z$ 外，还提供三个反抗旋转的力偶矩分量 $M_x, M_y, M_z$。
*   **推力轴承 (Thrust bearing)**：可以承受径向力 $R_x, R_z$ 以及轴向力 $R_y$。在某些情况下，为了满足静定条件，反力偶 $M_x, M_z$ 可假定为零。

---

### 第三部分：平衡条件 (Equilibrium Conditions)

**1. 二维平衡 (2D Equilibrium)**
*   **基本方程**：合力 $\Sigma F_x = 0$, $\Sigma F_y = 0$ 且合力矩 $\Sigma M_O = 0$（对平面内任意点 $O$ 的力矩之和为零）。
*   **替代方程组（共三种形式）**：
    *   两力一方程：$\Sigma F_x = 0$, $\Sigma F_y = 0$, $\Sigma M_A = 0$。
    *   两矩一方程：$\Sigma F_x = 0$, $\Sigma M_A = 0$, $\Sigma M_B = 0$（条件：A、B两点的连线不能垂直于 x 轴）。
    *   三矩方程：$\Sigma M_A = 0$, $\Sigma M_B = 0$, $\Sigma M_C = 0$（条件：A、B、C三点不能共线）。

**2. 三维平衡 (3D Equilibrium)**
*   **六个独立方程**：$\Sigma F_x = 0$, $\Sigma F_y = 0$, $\Sigma F_z = 0$ 以及 $\Sigma M_x = 0$, $\Sigma M_y = 0$, $\Sigma M_z = 0$。

---

### 第四部分：特殊构件与静定性 (Special Members & Determinacy)

**1. 特殊受力构件**
*   **二力构件 (Two-Force Members)**：仅受两个力作用而处于平衡的物体。这两个力必定大小相等、方向相反、共线，且与物体的形状无关（忽略自重）。
*   **三力构件 (Three-Force Members)**：受三个力作用平衡的物体，这三个力的作用线必须交于一点（共点），或者相互平行。

**2. 约束与静定性 (Constraints and Statical Determinacy)**
*   **静定 (Statically Determinate)**：约束数量刚好足以维持平衡状态，所有未知反力都可以通过平衡方程求出。
*   **超静定 (Statically Indeterminate)**：提供的外部约束多于维持平衡所需的数量，多余的支撑称为多余约束 (Redundant)。超静定次数等于未知力总数减去独立平衡方程的数量。
*   **不完全固定 (Incomplete Fixity/Partial Constraints)**：约束不足或分布不当，例如缺少对抗某个方向平动或绕某条轴线转动的约束。

### 第五部分：核心例题详细解析

#### 1. Sample Problem 3/2 (滑轮组张力计算)
**题目**：计算支撑 1000 lb 载荷的滑轮组中的绳索张力 $T$（$\theta = 30^\circ$），并求滑轮 C 轴承上的总受力大小。
**解析**：
*   **滑轮 A**：隔离滑轮 A，向上受两段绳索拉力 $T_1$ 和 $T_2$，向下受 1000 lb 的载荷。
    *   由力矩平衡 $\Sigma M_O = 0 \rightarrow T_1 \cdot r = T_2 \cdot r$，因此 $T_1 = T_2$。
    *   由力平衡 $\Sigma F_y = 0 \rightarrow T_1 + T_2 = 1000$，解得 $T_1 = T_2 = 500$ lb。
*   **滑轮 B**：同理，向上两股绳受力 $T_3 = T_4$，向下受 $T_2$。因此 $T_3 = T_4 = 500 / 2 = 250$ lb。
*   **滑轮 C**：力矩平衡表明张力通过滑轮不改变大小，所以外侧拉力 $T = T_3 = 250$ lb（角度 30° 不影响绕圆心的力矩）。
*   **计算滑轮 C 的轴承反力**：
    *   $\Sigma F_x = 0 \rightarrow 250 \cos 30^\circ - F_x = 0 \rightarrow F_x = 217$ lb。
    *   $\Sigma F_y = 0 \rightarrow F_y + 250 \sin 30^\circ - 250 = 0 \rightarrow F_y = 125$ lb。
    *   总反力 $F = \sqrt{F_x^2 + F_y^2} = \sqrt{217^2 + 125^2} = 250$ lb。

#### 2. Sample Problem 3/4 (悬臂起重机反力计算)
**题目**：计算支撑绳索的张力 $T$ 以及 A 处销轴的反力大小。横梁 AB 长 5 m，质量为 95 kg/m（重力约等于 4.66 kN 集中作用在中点）。
**解析**：
*   **建立受力分析图**：A 点受未知反力 $A_x$ 和 $A_y$，B 点受绳索拉力 $T$ (与水平呈 25°)，重力 4.66 kN 在距 A 端 2.5 m 处，10 kN 载荷在距 B 端 1.5 m 处。
*   **对 A 点取矩**：消除未知数 $A_x$ 和 $A_y$：
    *   $\Sigma M_A = 0 \rightarrow (T \cos 25^\circ)(0.25) + (T \sin 25^\circ)(5 - 0.12) - 10(5 - 1.5 - 0.12) - 4.66(2.5 - 0.12) = 0$。
    *   解方程得张力 $T = 19.61$ kN。
*   **求解 A 点反力**：
    *   $\Sigma F_x = 0 \rightarrow A_x - 19.61 \cos 25^\circ = 0 \rightarrow A_x = 17.77$ kN。
    *   $\Sigma F_y = 0 \rightarrow A_y + 19.61 \sin 25^\circ - 4.66 - 10 = 0 \rightarrow A_y = 6.37$ kN。
    *   A点总反力 $A = \sqrt{A_x^2 + A_y^2} = 18.88$ kN。
