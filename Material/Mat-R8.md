## 核心知识点梳理

### 一、 铁碳相图中的五大基本相与组织 
在 Fe-C 相图中，碳作为间隙杂质固溶在铁的晶格中。由于 FCC 和 BCC 晶格间隙大小不同，碳的溶解度也不同 。
1. **$\alpha$-铁素体 ($\alpha$-Ferrite)**：
   * **晶体结构**：BCC（体心立方）。
   * **特性**：碳的溶解度极低（在 727℃ 时达到最大值 0.022 wt%）。质地非常软且具有延展性 。在 768℃ 以下具有铁磁性 。
2. **$\gamma$-奥氏体 ($\gamma$-Austenite)**：
   * **晶体结构**：FCC（面心立方），间隙更大 。
   * **特性**：碳的最大溶解度大幅提升（在 1147℃ 时达到 2.14 wt%）。它是无磁性的 。
3. **$\delta$-铁素体 ($\delta$-Ferrite)**：
   * **特性**：BCC 结构，仅在极高温（1394℃~1538℃）下稳定存在，工程意义较小 。
4. **渗碳体 (Cementite, $Fe_3C$)**：
   * **特性**：碳含量为 6.70 wt% 的金属间化合物 。极硬且脆，是钢中强化的主要相 。它在室温下是亚稳态的，经过数年会缓慢分解为铁和石墨 。
5. **珠光体 (Pearlite)**：
   * **特性**：由 $\alpha$-铁素体和渗碳体 ($Fe_3C$) 交替排列组成的**层状 (Lamellar)** 共析组织 。其力学性能介于软韧的铁素体和硬脆的渗碳体之间 。

### 二、 铁碳相图的三大核心反应 (三大水平线) 
必须牢记这三个恒温反应的方程式、温度和成分点：
1. **共析反应 (Eutectoid Reaction)** —— **最重要的反应** 
   * **温度**：727℃ 
   * **反应式**：$\gamma (0.76\% C) \leftrightarrow \alpha (0.022\% C) + Fe_3C (6.7\% C)$ 
   * **产物**：珠光体 (Pearlite) 。
2. **共晶反应 (Eutectic Reaction)** 
   * **温度**：1147℃ 
   * **反应式**：$L (4.30\% C) \leftrightarrow \gamma (2.14\% C) + Fe_3C (6.7\% C)$ 
   * **产物**：莱氏体 (Ledeburite) 。
3. **包晶反应 (Peritectic Reaction)** 
   * **温度**：1493℃ 
   * **反应式**：$L + \delta \leftrightarrow \gamma$ 

### 三、 根据碳含量对铁合金的分类 
* **纯铁 (Pure Iron)**：$C < 0.008 wt\%$ 。
* **钢 (Steels)**：$0.008 wt\% < C < 2.14 wt\%$ 。
  * **亚共析钢 (Hypoeutectoid)**：$0.022\% < C < 0.76\%$。显微组织：**先共析铁素体 (Proeutectoid $\alpha$)** + 珠光体 。
  * **过共析钢 (Hypereutectoid)**：$0.76\% < C < 2.14\%$。显微组织：**先共析渗碳体 (Proeutectoid $Fe_3C$)** + 珠光体 。
* **铸铁 (Cast Irons)**：$2.14 wt\% < C < 6.70 wt\%$（通常在 3.0~4.5 wt%）。

### 四、 性能规律与合金元素的影响
* **碳含量的影响**：随着碳含量（即 $Fe_3C$ 比例）增加，钢的**拉伸强度和硬度增加**，但**延展性和冲击韧性下降**（变得更脆）。
* **合金元素的影响**：加入 Cr, Ni, Ti, Mo 等合金元素，会**显著改变共析温度和共析成分点**（例如，加入 Ti 或 Mo 会显著降低共析碳含量）。

## 典型例题详细说明

### 例题 1：杠杆定理在亚共析钢中的全面应用（必考计算）
**题目**：一种碳含量为 $C_0 = 0.30 wt\%$ 的碳钢，从高温奥氏体区缓慢冷却至 $400℃$。请计算在 $400℃$ 时（注：成分可近似取 727℃ 刚结束时的值）：
(1) 该合金中**珠光体 (Pearlite)** 和**先共析铁素体 (Proeutectoid $\alpha$)** 的质量分数？
(2) 该合金中**总铁素体 (Total $\alpha$)** 和**总渗碳体 (Total $Fe_3C$)** 的质量分数？
(3) 珠光体中包含的**共析铁素体 (Eutectoid $\alpha$)** 的质量分数是多少？

**详细解析**：
*(提示：在 400℃ 时，相关成分点近似为：$\alpha$ 相 $0.022\% C$，$Fe_3C$ 相 $6.7\% C$，共析点 $0.76\% C$)*

**(1) 计算微观组织（珠光体和先共析 $\alpha$）的比例：**
微观组织的形成取决于共析点 (0.76%) 发生的反应。我们将结线画在 $\alpha$ 相界 (0.022%) 和共析点 (0.76%) 之间。
* **珠光体分数 ($W_p$)**（相当于刚到 727℃ 时的剩余奥氏体）：
  $$W_p = \frac{C_0 - C_\alpha}{C_{eutectoid} - C_\alpha} = \frac{0.30 - 0.022}{0.76 - 0.022} = \frac{0.278}{0.738} \approx 37.7\%$$
* **先共析铁素体分数 ($W_{pro-\alpha}$)**：
  $$W_{pro-\alpha} = 1 - W_p = 1 - 37.7\% = 62.3\%$$

**(2) 计算相（总 $\alpha$ 和总 $Fe_3C$）的比例：**
相的比例需要跨越整个两相区（$\alpha + Fe_3C$），即结线端点为 0.022% 和 6.7%。
* **总渗碳体分数 ($W_{Fe_3C}$)**：
  $$W_{Fe_3C} = \frac{C_0 - C_\alpha}{C_{Fe_3C} - C_\alpha} = \frac{0.30 - 0.022}{6.70 - 0.022} = \frac{0.278}{6.678} \approx 4.16\%$$
* **总铁素体分数 ($W_{\alpha\_total}$)**：
  $$W_{\alpha\_total} = 1 - W_{Fe_3C} = 1 - 4.16\% = 95.84\%$$

**(3) 计算共析铁素体 (Eutectoid $\alpha$) 的比例：**
总铁素体由两部分组成：降温过程中先析出的（先共析 $\alpha$），以及共析反应生成的珠光体里面夹杂的（共析 $\alpha$）。
* **共析铁素体分数** = 总铁素体 - 先共析铁素体
  $$W_{eutectoid\_\alpha} = 95.84\% - 62.3\% = 33.54\%$$
*(验证：珠光体总量为 37.7%，里面包含铁素体 33.54% 和渗碳体 4.16%。33.54 + 4.16 = 37.7，逻辑完美闭环！)*
