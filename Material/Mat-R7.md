这是《材料导论》第七课的纯净笔记与重点梳理。本节课进入了材料科学最核心的工具之一：**相图 (Phase Diagrams)**。相图是理解合金设计、热处理工艺和微观结构演变的基础。

## 核心知识点梳理

### 一、 相图基础与基本概念
相图描述了在**热力学平衡**（温度、压力、成分不变时，系统处于自由能最低的稳定状态）下，材料的微观结构与成分、温度、压力的关系。

* **组元 (Component)**：构成系统的独立化学物质（如 Fe, C）。二元合金包含两个组元。
* **相 (Phase)**：材料中具有均匀的物理和化学性质、且有明显边界的区域。相取决于：
  1. 物质状态（固、液、气）。
  2. 晶体结构（单晶、多晶、非晶）。
  3. 成分组成：纯物质、化合物（如 $Mg_2Pb$）或**固溶体 (Solid solution)**。
* **固溶体**：由溶剂（基体）和溶质（加入的少量元素）组成的均匀混合物。
  * **置换固溶体 (Substitutional)**：溶质原子取代溶剂原子（如 Cu 溶于 Ni）。
  * **间隙固溶体 (Interstitial)**：溶质原子进入晶格间隙（如 C 溶于 Fe）。
* **成分表示 (Composition)**：
  * **质量分数 (wt%)**：$wt\% = \frac{m_i}{\sum m_i} \times 100\%$
  * **原子分数 (at%)**：$at\% = \frac{n_i}{\sum n_i} \times 100\%$ （$n_i$ 为原子数）

### 二、 完全互溶双元相图 (Complete Solubility / Isomorphous)
两个组元在固态和液态下都能以任意比例完全无限互溶（例如 Cu-Ni 系统）。
* **形成条件 (Hume-Rothery 规则)**：
  1. 晶体结构相同。
  2. 原子半径差小于 15% ($\Delta R < 15\%$ )。
  3. 电负性相近，化合价相同。
* **相图上的关键线**：
  * **液相线 (Liquidus line)**：液相区与固液两相区的分界线。高于此线全为液体。
  * **固相线 (Solidus line)**：固相区与固液两相区的分界线。低于此线全为固体。
* **完全互溶合金的力学性能规律**：
  随着第二种组元的加入（固溶强化效应），合金的**抗拉强度和硬度会升高**（通常在中间成分处达到峰值），而**延展性（塑性）会下降**。

### 三、 杠杆定理 (Lever Rule) 及推导
在两相区（如液态 L + 固态 $\alpha$）内，确定各相的成分和质量分数。
* **结线 (Tie line)**：在给定温度下画一条水平线，它与两条相界线的交点即为该温度下两相的**实际成分**。
* **质量分数的杠杆定理公式**：
  设整体成分为 $C_0$，水平结线与液相线交于 $C_L$，与固相线交于 $C_\alpha$。
  液相的质量分数：$X_L = \frac{C_\alpha - C_0}{C_\alpha - C_L}$ （对侧线段长 / 总长）
  固相的质量分数：$X_\alpha = \frac{C_0 - C_L}{C_\alpha - C_L}$
* **定理推导（基于质量守恒）**：
  设总质量为 1。固相分数 $X_\alpha$ 和液相分数 $X_L$ 满足 $X_\alpha + X_L = 1$。
  总合金中的溶质质量 = 固相中的溶质质量 + 液相中的溶质质量。
  $$C_0 \times 1 = C_\alpha \cdot X_\alpha + C_L \cdot X_L$$
  将 $X_\alpha = 1 - X_L$ 代入上式：
  $$C_0 = C_\alpha (1 - X_L) + C_L \cdot X_L$$
  $$C_0 = C_\alpha - C_\alpha \cdot X_L + C_L \cdot X_L$$
  $$C_\alpha - C_0 = X_L (C_\alpha - C_L) \implies X_L = \frac{C_\alpha - C_0}{C_\alpha - C_L}$$

### 四、 吉布斯相律 (Gibbs Phase Rule)
用于计算系统在不改变相数的情况下，可以独立改变的强度变量（温度、压力、成分）的数目（自由度）。
* **通用公式**：$$u = n - r + 2$$
  （$u$ 为自由度；$n$ 为组元数；$r$ 为存在的相数；2 代表温度和压力两个变量）。
* **恒压修正公式**：在大多数冶金过程中，压力固定为 1 atm，压力不再是变量，公式简化为：
  $$u = n - r' + 1$$ （$r'$ 代表不包含气相的凝聚相数目）。

### 五、 共晶相图 (Eutectic Phase Diagram) 与溶解度极限
当两组元不能完全互溶时，会出现溶解度极限（**固溶线 Solvus line**）。
* **共晶反应 (Eutectic Reaction)**：液相在特定温度（共晶温度 $T_E$）下，同时结晶出两种不同的固相。
  $$L \leftrightarrow \alpha + \beta$$
* **共晶点特征**：
  在共晶点，存在 L, $\alpha$, $\beta$ 三相共存。根据吉布斯相律 $u = 2 - 3 + 1 = 0$。自由度为 0 意味着在共晶反应完成前，**温度保持恒定**（冷却曲线出现水平段），且三相的成分也是固定的。
* **共晶微观组织 (Eutectic Structure)**：
  由于固相 $\alpha$ 和 $\beta$ 需要通过原子的扩散来分离不同的组分，它们通常交替生长，形成**层状 (Lamellar)** 组织。
* **亚共晶 (Hypoeutectic) 与过共晶 (Hypereutectic)**：
  * **亚共晶**：成分在纯物质与共晶点之间。冷却时先析出**初生相 (Primary $\alpha$)**，剩余液体达到共晶温度时转变为共晶组织 ($\alpha + \beta$)。
  * 显微组织由“初生相颗粒”与“层状共晶基体”混合组成。

### 六、 金属间化合物与四大基本相变
* **金属间化合物 (Intermetallic Compounds)**：具有明确化学分子式（如 $Mg_2Pb$）的相。在相图上表现为一条垂直线。它可以把一个复杂的相图分割成两个简单的二元共晶相图。
* **四大基本等温可逆反应**（必须牢记）：
  1. **共晶 (Eutectic)**：$L \leftrightarrow \alpha + \beta$ （一液变两固）
  2. **共析 (Eutectoid)**：$\gamma \leftrightarrow \alpha + \beta$ （一固变两新固，如钢的奥氏体转珠光体）
  3. **包晶 (Peritectic)**：$L + \alpha \leftrightarrow \beta$ （一液一固反应生成新固）
  4. **包析 (Peritectoid)**：$\alpha + \beta \leftrightarrow \gamma$ （两固反应生成新固）

## 典型例题详细解析

### 例题 1：杠杆定理在亚共晶组织中的应用（易错核心考点）
**题目**：在 Pb-Sn 相图中（已知共晶温度 $183^\circ\text{C}$，共晶成分 $61.9\% \text{ Sn}$。在 $183^\circ\text{C}$ 时，$\alpha$ 相最大固溶度为 $18.3\% \text{ Sn}$，$\beta$ 相最大固溶度为 $97.8\% \text{ Sn}$）。现有一个总成分为 $C_0 = 40\% \text{ Sn}$ 的亚共晶合金。
请计算在温度刚好降至 $183^\circ\text{C}$ 之下时：
(1) 该合金中总的 $\alpha$ 相和 $\beta$ 相的质量分数？
(2) 该合金中**初生 $\alpha$ 相 (Primary $\alpha$)** 和**共晶组织 (Eutectic structure)** 的质量分数？

**详细解析**：
这题揭示了“相的比例”和“微观组织的比例”是两个完全不同的概念。
**(1) 计算总 $\alpha$ 和总 $\beta$ 的比例**：
我们要看整个相图的最宽的结线（横跨整个两相区）。
左端点（$\alpha$ 相成分） $C_\alpha = 18.3$
右端点（$\beta$ 相成分） $C_\beta = 97.8$
合金整体成分 $C_0 = 40$
* 总 $\beta$ 相的比例：
  $$W_{\beta_{total}} = \frac{C_0 - C_\alpha}{C_\beta - C_\alpha} = \frac{40 - 18.3}{97.8 - 18.3} = \frac{21.7}{79.5} \approx 27.3\%$$
* 总 $\alpha$ 相的比例：
  $$W_{\alpha_{total}} = 1 - W_{\beta_{total}} = 72.7\%$$

**(2) 计算初生 $\alpha$ 相和共晶组织的比例**：
初生相是在降温到共晶温度*之前*从液体中析出的。当到达共晶温度时，剩余的**整个液相**会瞬间转变为共晶组织。因此，**共晶组织的比例就等于刚好到达共晶温度上方时的液相比例**。
我们要把结线画在固相线和**共晶点**之间（即刚才发生反应的两相：$\alpha$ 和 $L$）。
左端点（此时 $\alpha$ 相成分） $C_\alpha = 18.3$
右端点（此时液相成分，即共晶成分） $C_L = C_{eutectic} = 61.9$
合金整体成分 $C_0 = 40$
* 共晶组织（即剩余液相）的比例：
  $$W_{eutectic} = W_L = \frac{C_0 - C_\alpha}{C_L - C_\alpha} = \frac{40 - 18.3}{61.9 - 18.3} = \frac{21.7}{43.6} \approx 49.8\%$$
* 初生 $\alpha$ 相的比例：
  $$W_{primary\_\alpha} = 1 - W_{eutectic} \approx 50.2\%$$
*(注意：总 $\alpha$ 相 = 初生 $\alpha$ 相 + 共晶组织中包含的 $\alpha$ 相。72.7% = 50.2% + 剩余部分。逻辑完全吻合！)*

### 例题 2：吉布斯相律分析
**题目**：在纯金属完全熔化的液态区，自由度是多少？在两元合金的共晶线上（三相共存），自由度是多少？（假设恒压 $1 \text{ atm}$）。

**详细解析**：
使用恒压公式 $u = n - r' + 1$。
* 对于纯金属液态区：组元数 $n = 1$（纯金属），相数 $r' = 1$（只有液相）。
  $$u = 1 - 1 + 1 = 1$$。这意味着你只能独立改变一个变量（温度）。
* 对于二元合金共晶线上：组元数 $n = 2$，相数 $r' = 3$（液相 L + 固相 $\alpha$ + 固相 $\beta$ 同时存在）。
  $$u = 2 - 3 + 1 = 0$$。自由度为0，说明在共晶转变完成前，系统的温度不能发生改变（被“锁定”了）。
