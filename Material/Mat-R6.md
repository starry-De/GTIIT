这是《材料导论》第六课的纯净笔记与重点梳理。本节课主要讨论材料在**动态交变载荷（疲劳）**和**高温恒定载荷（蠕变）**下的失效机制。这两种失效方式在工程实际中极其常见，且往往没有明显的宏观塑性变形前兆，因此非常危险。

## 核心知识点梳理

### 一、 疲劳 (Fatigue)
疲劳是指材料在动态和交变（循环）应力作用下发生的失效。
* **核心特征**：
  * 疲劳断裂发生的应力水平**远低于**材料在静态载荷下的抗拉强度或屈服强度。
  * 造成了约 90% 的金属结构失效。
  * 失效具有**突发性 (Catastrophic)**，断裂前几乎没有宏观塑性变形警告，断裂面通常垂直于主拉应力方向。

#### 1. 交变应力参数 (Cyclic Stresses)
循环应力可以是完全对称的、不对称的或随机的。相关计算公式如下：
* **平均应力 (Mean stress, $\sigma_m$)**：
  $$\sigma_m = \frac{\sigma_{max} + \sigma_{min}}{2}$$
* **应力幅 (Stress amplitude, $\sigma_a$)**：
  $$\sigma_a = \frac{\sigma_{max} - \sigma_{min}}{2}$$
* **应力范围 (Stress range, $\sigma_r$)**：
  $$\sigma_r = \sigma_{max} - \sigma_{min}$$
* **应力比 (Stress ratio, $R$)**：
  $$R = \frac{\sigma_{min}}{\sigma_{max}}$$
*(注意：压应力带有负号。)*

#### 2. S-N 曲线 (应力-寿命曲线)
通过不同应力幅 ($\sigma_a$或 $S$) 进行疲劳试验，记录断裂时的循环次数 ($N_f$)。由于 $N_f$ 跨度很大，通常横轴采用对数坐标 $\log N$。
* **疲劳极限 / 持久极限 (Fatigue Limit / Endurance Limit)**：
  对于某些材料（如**钢铁**、**钛合金**），S-N曲线在低应力区会趋于水平。这个水平渐近线对应的应力就是疲劳极限。**只要外加交变应力低于疲劳极限，材料具有无限长的疲劳寿命（永远不会疲劳断裂）**。
* **疲劳强度 (Fatigue Strength)**：
  对于很多非铁金属（如**铝合金**、铜合金），S-N曲线一直下降，**不存在**疲劳极限。因此只能定义“疲劳强度”：即在指定的循环次数（如 $10^7$ 次）下材料发生断裂时的应力值。
* **疲劳寿命 (Fatigue Life, $N_f$)**：在某一特定应力水平下，导致材料断裂的循环次数。

#### 3. 疲劳失效的过程与断口形貌
1. **裂纹萌生 (Crack initiation)**：通常萌生于材料表面、应力集中处（如划痕、锐角、螺纹）。
2. **裂纹扩展 (Crack propagation)**：每次应力循环促使裂纹向前推进一段距离。断口上常留下特征性的**疲劳辉纹 (Striations)** 或 **贝壳状暗纹 (Benchmarks)**。
3. **最终断裂 (Final failure)**：当剩余横截面积无法承受最大载荷时，发生瞬间突发性断裂。

#### 4. 提高疲劳寿命的方法
* **降低平均应力**：平均拉应力越高，疲劳寿命越短。
* **改善设计**：消除锐角，增加圆角过渡 (Fillets)，减少应力集中。
* **表面处理**：
  * **抛光 (Polishing)**：去除表面微裂纹。
  * **喷丸处理 (Shot Peening)**：用高速弹丸轰击材料表面，在表面引入**残余压应力 (Compressive residual stress)**。因为表面裂纹需要在拉应力下才会张开扩展，压应力能有效抑制表面裂纹的萌生和早期扩展。
  * **表面硬化 (Case Hardening)**：如渗碳、渗氮，既提高表面硬度又引入残余压应力。

### 二、 蠕变 (Creep)
蠕变是指材料在**恒定载荷（或恒定应力）**和**高温**环境下，随时间推移而发生的缓慢、永久性（塑性）变形。
* **高温条件**：通常在温度 $T > 0.4 T_m$ 时发生（$T_m$ 为材料的绝对熔点，单位为开尔文 K）。对于低熔点材料（如铅），室温下也会发生蠕变。

#### 1. 蠕变曲线与三个阶段
在恒定温度和载荷下，记录应变随时间的变化：
* **第一阶段 (Primary / Transient Creep)**：蠕变速率（曲线斜率）随时间**减小**。这是因为材料发生了应变硬化。
* **第二阶段 (Secondary / Steady-state Creep)**：蠕变速率保持**恒定**，曲线呈直线。此时应变硬化与高温带来的回复软化达到了动态平衡。**稳态蠕变速率 ($\dot{\epsilon}_s$) 是蠕变设计中最重要的参数**。
* **第三阶段 (Tertiary Creep)**：蠕变速率急剧**增加**，材料内部出现微孔洞、微裂纹，伴随颈缩，最终导致断裂 (Rupture)。

#### 2. 稳态蠕变速率公式
稳态蠕变速率 $\dot{\epsilon}_s$ 受到温度 $T$ 和施加应力 $\sigma$ 的高度影响：
$$\dot{\epsilon}_s = K_1 \sigma^n \exp\left(-\frac{Q_c}{RT}\right)$$
* $K_1$, $n$: 材料常数。
* $Q_c$: 蠕变活化能。
*(注：如果只考虑应力影响，可简化为 $\dot{\epsilon}_s = K \sigma^n$)*

#### 3. Larson-Miller 参数 (LMP)
工程师需要预测材料在高温下能服役多长时间（如涡轮叶片服役几年），但实验室无法等几年。LMP 提供了一种用**短时间/更高温度**试验来等效预测**长时间/较低温度**寿命的方法。
$$LMP = T(C + \log t_r)$$
* $T$: 绝对温度 (通常用 Kelvin K)。
* $t_r$: 断裂时间 (Rupture time，通常用小时 h)。
* $C$: 常数，对于大多数合金通常取 20。
**核心结论**：在相同的应力水平下，同一个材料的 LMP 是一个恒定值。

#### 4. 提高抗蠕变性能的方法
蠕变在微观上通常涉及位错攀移和**晶界滑动 (Grain boundary sliding)**。
* 选择高熔点、高弹性模量的材料。
* **增大晶粒尺寸 (Larger grain size)**：这是与常温强度（细晶强化）完全相反的结论！在高温下，晶界较弱且容易滑动，晶粒越大，晶界越少，抗蠕变性能越好。
* **使用单晶材料 (Single-crystal blades)**：消除所有晶界，是喷气式发动机涡轮叶片的终极解决方案。
* 添加固溶体合金元素。

## 典型例题详细解析

### 例题 1：疲劳循环应力参数计算
**题目**：一个连杆在发动机运转时，承受的拉力最大值为 1000 N，同时在另一个冲程中承受 400 N 的压力。已知连杆横截面积为 $10 \text{ mm}^2$。计算其承受的：(1) 最大应力和最小应力；(2) 平均应力 $\sigma_m$；(3) 应力幅 $\sigma_a$；(4) 应力比 $R$。

**详细解析**：
1. **明确最大/最小应力（注意符号）**：
   拉力为正，压力为负。
   $$\sigma_{max} = \frac{1000 \text{ N}}{10 \text{ mm}^2} = 100 \text{ MPa}$$
   $$\sigma_{min} = \frac{-400 \text{ N}}{10 \text{ mm}^2} = -40 \text{ MPa}$$
2. **计算平均应力**：
   $$\sigma_m = \frac{100 + (-40)}{2} = \frac{60}{2} = 30 \text{ MPa}$$
3. **计算应力幅**：
   $$\sigma_a = \frac{100 - (-40)}{2} = \frac{140}{2} = 70 \text{ MPa}$$
4. **计算应力比**：
   $$R = \frac{-40}{100} = -0.4$$

### 例题 2：Larson-Miller 参数 (LMP) 计算与寿命预测
**题目**：已知某种 S-590 铁基合金在应力为 140 MPa 时的 Larson-Miller 参数值为 $24 \times 10^3$ (其中温度 $T$ 的单位使用 Kelvin 开尔文，$t_r$ 单位为小时，常数 $C=20$)。
(1) 如果该合金在 140 MPa 的应力下，于 $800^\circ\text{C}$ 工作，求其预期断裂时间 $t_r$。
(2) 如果希望它在相同的应力下工作至少 100,000 小时，它所能承受的最高温度是多少 $^\circ\text{C}$？

**详细解析**：
(1) **统一温度单位并代入 LMP 公式**：
   绝对温度 $T = 800 + 273 = 1073 \text{ K}$。
   $$LMP = T(20 + \log t_r)$$
   $$24000 = 1073 \times (20 + \log t_r)$$
   $$20 + \log t_r = \frac{24000}{1073} \approx 22.367$$
   $$\log t_r = 22.367 - 20 = 2.367$$
   $$t_r = 10^{2.367} \approx 233 \text{ 小时}$$

(2) **已知寿命求温度**：
   此时 $t_r = 100,000 = 10^5 \text{ 小时}$，因此 $\log t_r = \log(10^5) = 5$。
   $$24000 = T(20 + 5)$$
   $$24000 = 25 T$$
   $$T = \frac{24000}{25} = 960 \text{ K}$$
   转化为摄氏度：$T(^\circ\text{C}) = 960 - 273 = 687 ^\circ\text{C}$。
**结论**：如果想让零件在同等应力下服役更长时间，必须降低工作温度。
