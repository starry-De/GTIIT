# 常微分方程 (ODE) 第六讲：核心考点纯净版笔记

本讲专攻二阶线性**非齐次**微分方程：$y'' + p(t)y' + q(t)y = g(t)$。这里的 $g(t) \neq 0$ 代表系统受到了外部持续的驱动力。

---

## 一、 非齐次方程的终极解结构 (定理 3.5.2)

非齐次方程的通解，永远由两个部分“拼装”而成：
$$y(t) = y_c(t) + Y_p(t)$$
* **$y_c(t)$ (齐次通解)**：令 $g(t)=0$，算出对应齐次方程的通解 $c_1y_1(t) + c_2y_2(t)$。这代表系统的**固有自然响应**。
* **$Y_p(t)$ (特解)**：寻找**任意一个**满足原非齐次方程的解。这代表系统在外部驱动力下的**强迫响应**。

**解题总路线**：先求 $y_c$，再求 $Y_p$，最后把它们加起来！

---

## 二、 求解 $Y_p$ 武器一：待定系数法 (Undetermined Coefficients)

**适用条件**：常系数方程，且右边的 $g(t)$ 必须是**多项式、指数函数、正弦/余弦函数**或它们的乘积。
**核心思想**：“依葫芦画瓢”。$g(t)$ 长什么样，我们就猜 $Y_p$ 也长什么样，然后代入方程把系数反算出来。

### 1. 终极猜解查表指南
假设 $g(t)$ 包含 $e^{\alpha t} \cos(\beta t)$ 或 $e^{\alpha t} \sin(\beta t)$ 以及多项式 $P_n(t)$，我们的猜测形式为：
$$Y_p(t) = t^s \cdot (\text{带未知系数的多项式}) \cdot e^{\alpha t} \cos(\beta t) + \dots$$

**【极其重要的 $t^s$ 冲突修正法则】**
算完齐次通解 $y_c$ 后，必须检查你猜的 $Y_p$ 基础形式是否和 $y_c$ 中的项**撞车（线性相关）**。
* 如果不撞车：$s = 0$（不需要乘 $t$）。
* 如果撞车了（即 $\alpha + \beta i$ 刚好是特征方程的根）：
    * 如果是单根：$s = 1$（整个猜想式乘以 $t$）。
    * 如果是重根：$s = 2$（整个猜想式乘以 $t^2$）。
   * 如何判断有几个 $t$?
     * 本质上看右端项 $g(t)$对应的“特征”在左边特征方程**出现了几次**，这个次数k就是$t$的幂次 $t^{k}$

### 2. 幻灯片例题超详细解析

**例题 1：冲突修正实战**
**题目**：求 $y'' - 3y' - 4y = 5e^{-t}$ 的特解。
**解析**：
1. **先算齐次解找特征根**：$r^2 - 3r - 4 = 0 \implies r = 4, -1$。所以 $y_c = c_1 e^{4t} + c_2 e^{-t}$。
2. **初步猜想**：因为 $g(t) = 5e^{-t}$，我们初步猜 $Y_p = A e^{-t}$。
3. **检查冲突**：我们猜的 $A e^{-t}$ 竟然和齐次解里的 $c_2 e^{-t}$ **撞车了**！（此时 $\alpha = -1$ 正好是特征根）。
4. **启动修正**：必须乘上 $t^1$。最终猜测形态为 $Y_p = A t e^{-t}$。
5. **代入求解**：
   $Y_p' = A e^{-t} - A t e^{-t}$
   $Y_p'' = -2A e^{-t} + A t e^{-t}$
   代入原方程：$(-2A e^{-t} + A t e^{-t}) - 3(A e^{-t} - A t e^{-t}) - 4(A t e^{-t}) = 5e^{-t}$
   化简左边：$(-2A - 3A)e^{-t} + (A + 3A - 4A)t e^{-t} = -5A e^{-t} = 5e^{-t}$
   所以 $-5A = 5 \implies A = -1$。
**最终特解**：$Y_p(t) = -t e^{-t}$。

**例题 2：复数形式的猜测**
**题目**：求 $y'' - 3y' - 4y = -8e^t \cos(2t)$ 的特解。
**解析**：
1. 齐次根依然是 $r=4, -1$。
2. $g(t)$ 中 $\alpha = 1, \beta = 2$。复合根 $1+2i$ 不是特征根，**无冲突**。
3. **完整猜测**（注意：只要有 $\cos$，就必须同时包含 $\sin$ 和 $\cos$）：
   $$Y_p = e^t (A\cos 2t + B\sin 2t)$$
4. 求导代入原方程，展开并合并同类项，比对等式左右两边 $\cos$ 和 $\sin$ 的系数，可解出一个关于 $A$ 和 $B$ 的二元一次方程组，解出即可。

---

## 三、 求解 $Y_p$ 武器二：常数变易法 (Variation of Parameters)

**适用条件**：万能！无论 $g(t)$ 是 $\tan(t)$、$\ln(t)$ 还是什么不符合待定系数法的分式，只要能求出齐次解 $y_1, y_2$，就能用它。
**核心思想**：设 $Y_p(t) = u_1(t)y_1(t) + u_2(t)y_2(t)$。

### 1. 终极公式 (由克莱姆法则推导)
不需要每次都推导方程组，直接死记这两个积分公式：
$$u_1'(t) = \frac{-y_2(t)g(t)}{W[y_1, y_2](t)}$$
$$u_2'(t) = \frac{y_1(t)g(t)}{W[y_1, y_2](t)}$$
*【致命易错点】：使用公式的前提是，原方程必须是标准形式 $y'' + p(t)y' + q(t)y = g(t)$，即 $y''$ 的系数必须强行化为 1，此时等号右边的才是真正的 $g(t)$。*

### 2. 例题超详细解析

**例题 1：右侧是非标准函数**
**题目**：解 $y'' + 4y = 8\tan(t)$ 
**解析**：
1. **齐次解**：$r^2 + 4 = 0 \implies r = \pm 2i$。得 $y_1 = \cos(2t), \ y_2 = \sin(2t)$。
2. **算 Wronskian**：$W = \cos(2t) \cdot 2\cos(2t) - (-2\sin(2t))\sin(2t) = 2(\cos^2 2t + \sin^2 2t) = 2$。
3. **套公式求 $u_1, u_2$**：
   $u_1' = \frac{-\sin(2t) \cdot 8\tan t}{2} = -4\sin(2t)\tan t = -4(2\sin t\cos t)\frac{\sin t}{\cos t} = -8\sin^2 t = -4(1-\cos 2t)$
   积分得：$u_1 = -4t + 2\sin(2t)$
   
   $u_2' = \frac{\cos(2t) \cdot 8\tan t}{2} = 4\cos(2t)\tan t = 4(2\cos^2 t - 1)\frac{\sin t}{\cos t} = 8\sin t\cos t - 4\tan t = 4\sin(2t) - 4\tan t$
   积分得：$u_2 = -2\cos(2t) + 4\ln|\cos t|$
4. **【完整组装 $Y_p$ 过程】**：
   根据公式 $Y_p(t) = u_1(t)y_1(t) + u_2(t)y_2(t)$，我们代入全部项：
   $$Y_p(t) = \big[ -4t + 2\sin(2t) \big]\cos(2t) + \big[ -2\cos(2t) + 4\ln|\cos t| \big]\sin(2t)$$
   将其彻底展开：
   $$Y_p(t) = -4t\cos(2t) + 2\sin(2t)\cos(2t) - 2\cos(2t)\sin(2t) + 4\sin(2t)\ln|\cos t|$$
   你会发现，中间的两项 $+2\sin(2t)\cos(2t)$ 和 $-2\cos(2t)\sin(2t)$ 完美抵消了！
   **最终特解**：
   $$Y_p(t) = -4t\cos(2t) + 4\sin(2t)\ln|\cos t|$$


**例题 2：综合变态大题 (欧拉方程 + 常数变易法 + 初值问题)**
**题目**：解 $t^2 y'' - 2y = 3t^2 - 1$，满足 $y(1)=0, y'(1)=0$ 
**解析**：
1. **化标准型**：提取 $g(t)$ 前必须同除以 $t^2$：
   $y'' - \frac{2}{t^2}y = 3 - \frac{1}{t^2} \implies g(t) = 3 - t^{-2}$
2. **解齐次方程 (欧拉方程)**：$t^2 y'' - 2y = 0$。代入 $y=t^r$，得 $r(r-1) - 2 = 0 \implies r^2 - r - 2 = 0 \implies r=2, -1$。
   所以 $y_1 = t^2, \ y_2 = t^{-1}$。
3. **算 Wronskian**：$W = t^2(-t^{-2}) - (2t)(t^{-1}) = -1 - 2 = -3$。
4. **常数变易法求 $Y_p$**：
   $u_1' = \frac{-t^{-1}(3 - t^{-2})}{-3} = t^{-1} - \frac{1}{3}t^{-3} \implies u_1 = \ln t + \frac{1}{6}t^{-2}$
   $u_2' = \frac{t^2(3 - t^{-2})}{-3} = -t^2 + \frac{1}{3} \implies u_2 = -\frac{1}{3}t^3 + \frac{1}{3}t$
   装配 $Y_p = u_1(t^2) + u_2(t^{-1}) = t^2\ln t + \frac{1}{6} - \frac{1}{3}t^2 + \frac{1}{3} = t^2\ln t - \frac{1}{3}t^2 + \frac{1}{2}$。
5. **【完整代入初值求解过程】**：
   首先，我们写出包含齐次解和特解的完整通解：
   $$y(t) = c_1 t^2 + c_2 t^{-1} + t^2\ln t - \frac{1}{3}t^2 + \frac{1}{2}$$
   由于 $-\frac{1}{3}t^2$ 和第一项 $c_1 t^2$ 是同类项，我们可以把它吸收进常数里（令新的常数 $C_1 = c_1 - \frac{1}{3}$），通解化简为：
   $$y(t) = C_1 t^2 + c_2 t^{-1} + t^2\ln t + \frac{1}{2}$$
   对通解求导，准备代入速度初值（注意 $t^2\ln t$ 要用乘积求导法则）：
   $$y'(t) = 2C_1 t - c_2 t^{-2} + \left( 2t\ln t + t^2 \cdot \frac{1}{t} \right) = 2C_1 t - c_2 t^{-2} + 2t\ln t + t$$
   现在，代入初始条件 $y(1)=0$ 和 $y'(1)=0$：
   * 代入 $y(1)=0$：
     $$C_1(1)^2 + c_2(1)^{-1} + (1)^2\ln(1) + \frac{1}{2} = 0 \implies C_1 + c_2 + 0 + 0.5 = 0 \implies C_1 + c_2 = -0.5$$
   * 代入 $y'(1)=0$：
     $$2C_1(1) - c_2(1)^{-2} + 2(1)\ln(1) + 1 = 0 \implies 2C_1 - c_2 + 0 + 1 = 0 \implies 2C_1 - c_2 = -1$$
   现在我们得到了一个简单的二元一次方程组：
   $$ \begin{cases} C_1 + c_2 = -0.5 \quad \text{①} \\ 2C_1 - c_2 = -1 \quad \text{②} \end{cases} $$
   将 ① 式和 ② 式相加，消去 $c_2$：
   $$3C_1 = -1.5 \implies C_1 = -0.5$$
   将 $C_1 = -0.5$ 代回 ① 式：
   $$-0.5 + c_2 = -0.5 \implies c_2 = 0$$
   **最终特解**：把求出的 $C_1$ 和 $c_2$ 塞回刚才化简的通解中：
   $$y(t) = -0.5t^2 + t^2\ln t + 0.5$$

# 常微分方程 (ODE) 第七讲：待定系数法综合大练兵 

第七讲是纯粹的实战课。主要目标是彻底巩固第六讲中**“待定系数法 (Undetermined Coefficients)”**的查表猜解与**“冲突修正法则 (乘以 $t^s$)”**。

本讲幻灯片提供了 5 道极具代表性的综合大题，完美覆盖了“多项式”、“三角函数”、“单根冲突”以及“重根冲突”的所有情况。下面为您提供**绝对不跳步、代数过程全展开**的超详细解析。

---

## 核心复习：冲突修正法则 ($t^s$)
在猜特解 $Y_p$ 时，如果猜想的形式与齐次方程的通解 $y_c$ 中的项**长得一模一样（即线性相关）**，就会发生冲突，代入原方程后会全部抵消为0。
* **无冲突**：$s=0$ (正常猜)。
* **与单实根/单复根冲突**：$s=1$ (整个猜想式乘以 $t$)。
* **与重实根冲突**：$s=2$ (整个猜想式乘以 $t^2$)。

---

## 幻灯片 5 道终极例题全解析

### 例题 1：多项式激励 (无冲突)
**题目**：解 $y'' - y' - 2y = -2t + 4t^2$
**解析**：
1. **解齐次方程**：
   特征方程 $r^2 - r - 2 = 0 \implies (r-2)(r+1) = 0 \implies r_1 = 2, r_2 = -1$。
   齐次解 $y_c = c_1 e^{2t} + c_2 e^{-t}$。
2. **假设特解 $Y_p$**：
   右侧 $g(t) = 4t^2 - 2t$ 是二次多项式。齐次解中没有多项式项，**无冲突**。
   猜想：$Y_p = At^2 + Bt + C$
3. **求导并代入**：
   $Y_p' = 2At + B$
   $Y_p'' = 2A$
   代入原方程 $y'' - y' - 2y = -2t + 4t^2$：
   $(2A) - (2At + B) - 2(At^2 + Bt + C) = 4t^2 - 2t$
4. **展开并合并同类项**：
   $-2At^2 + (-2A - 2B)t + (2A - B - 2C) = 4t^2 - 2t + 0$
5. **比对系数解方程**：
   * $t^2$ 项：$-2A = 4 \implies A = -2$
   * $t$ 项：$-2A - 2B = -2 \implies -2(-2) - 2B = -2 \implies 4 - 2B = -2 \implies -2B = -6 \implies B = 3$
   * 常数项：$2A - B - 2C = 0 \implies 2(-2) - 3 - 2C = 0 \implies -4 - 3 - 2C = 0 \implies -2C = 7 \implies C = -3.5$
6. **最终通解**：
   $$y(t) = c_1 e^{2t} + c_2 e^{-t} - 2t^2 + 3t - 3.5$$

---

### 例题 2：三角函数激励 (无冲突)
**题目**：解 $y'' - 3y' - 4y = 2\sin(t)$
**解析**：
1. **解齐次方程**：
   特征方程 $r^2 - 3r - 4 = 0 \implies (r-4)(r+1) = 0 \implies r = 4, -1$。
   齐次解 $y_c = c_1 e^{4t} + c_2 e^{-t}$。
2. **假设特解 $Y_p$**：
   右侧 $g(t) = 2\sin(t)$，对应特征根为 $\pm i$，与齐次解的 $4, -1$ **无冲突**。
   猜想：$Y_p = A\cos(t) + B\sin(t)$
3. **求导并代入**：
   $Y_p' = -A\sin(t) + B\cos(t)$
   $Y_p'' = -A\cos(t) - B\sin(t)$
   代入原方程：
   $(-A\cos(t) - B\sin(t)) - 3(-A\sin(t) + B\cos(t)) - 4(A\cos(t) + B\sin(t)) = 2\sin(t)$
4. **展开并合并同类项**：
   $\cos(t)[-A - 3B - 4A] + \sin(t)[-B + 3A - 4B] = 2\sin(t)$
   $\cos(t)[-5A - 3B] + \sin(t)[3A - 5B] = 0\cos(t) + 2\sin(t)$
5. **比对系数解方程**：
   * $\cos$ 项：$-5A - 3B = 0 \implies B = -\frac{5}{3}A$
   * $\sin$ 项：$3A - 5B = 2 \implies 3A - 5(-\frac{5}{3}A) = 2 \implies 3A + \frac{25}{3}A = 2 \implies \frac{34}{3}A = 2 \implies A = \frac{6}{34} = \frac{3}{17}$
   * 回代求 $B$：$B = -\frac{5}{3} \times \frac{3}{17} = -\frac{5}{17}$
6. **最终通解**：
   $$y(t) = c_1 e^{4t} + c_2 e^{-t} + \frac{3}{17}\cos(t) - \frac{5}{17}\sin(t)$$

---

### 例题 3：常数项单根冲突 (必须乘 $t$)
**题目**：解 $y'' + 2y' = 3 + 4\sin(2t)$
**解析**：
1. **解齐次方程**：
   特征方程 $r^2 + 2r = 0 \implies r(r+2) = 0 \implies r = 0, -2$。
   齐次解 $y_c = c_1 e^{0t} + c_2 e^{-2t} = c_1 + c_2 e^{-2t}$。
2. **假设特解 $Y_p$** (分两部分处理)：
   * 对于 $g_1(t) = 3$：常数项相当于 $3e^{0t}$，特征根为 $0$。发现与齐次解的单根 $r=0$ **冲突了**！所以原计划猜 $A$，必须乘以 $t$，修正为 $At$。
   * 对于 $g_2(t) = 4\sin(2t)$：对应根 $\pm 2i$，**无冲突**。猜想为 $B\cos(2t) + C\sin(2t)$。
   综合猜想：$Y_p = At + B\cos(2t) + C\sin(2t)$
3. **求导并代入**：
   $Y_p' = A - 2B\sin(2t) + 2C\cos(2t)$
   $Y_p'' = -4B\cos(2t) - 4C\sin(2t)$
   代入原方程 $y'' + 2y' = 3 + 4\sin(2t)$：
   $(-4B\cos(2t) - 4C\sin(2t)) + 2(A - 2B\sin(2t) + 2C\cos(2t)) = 3 + 4\sin(2t)$
4. **展开并合并同类项**：
   $(2A) + \cos(2t)[-4B + 4C] + \sin(2t)[-4C - 4B] = 3 + 0\cos(2t) + 4\sin(2t)$
5. **比对系数解方程**：
   * 常数项：$2A = 3 \implies A = 1.5$
   * $\cos$ 项：$-4B + 4C = 0 \implies B = C$
   * $\sin$ 项：$-4C - 4B = 4 \implies -8B = 4 \implies B = -0.5$，所以 $C = -0.5$
6. **最终通解**：
   $$y(t) = c_1 + c_2 e^{-2t} + 1.5t - 0.5\cos(2t) - 0.5\sin(2t)$$

---

### 例题 4：重实根极度冲突 (必须乘 $t^2$)
**题目**：解 $y'' - 2y' + y = e^t$
**解析**：
1. **解齐次方程**：
   特征方程 $r^2 - 2r + 1 = 0 \implies (r-1)^2 = 0 \implies r = 1$ (重根)。
   齐次解 $y_c = c_1 e^t + c_2 t e^t$。
2. **假设特解 $Y_p$**：
   右侧 $g(t) = e^t$，特征根为 $r=1$。发现与齐次解发生了**重根冲突**（不仅和 $e^t$ 撞车，乘一个 $t$ 变成 $te^t$ 后依然撞车）。
   因此，必须乘以 $t^2$。
   猜想：$Y_p = A t^2 e^t$
3. **求导并代入 (使用乘积求导法则)**：
   $Y_p' = 2At e^t + A t^2 e^t$
   $Y_p'' = (2A e^t + 2At e^t) + (2At e^t + A t^2 e^t) = e^t(2A + 4At + At^2)$
   代入原方程 $y'' - 2y' + y = e^t$：
   $e^t(2A + 4At + At^2) - 2(2At e^t + A t^2 e^t) + (A t^2 e^t) = e^t$
4. **彻底展开并合并同类项**：
   提出公因式 $e^t$：
   $e^t [ (A - 2A + A)t^2 + (4A - 4A)t + 2A ] = e^t$
   完美抵消，只剩下：
   $e^t [ 2A ] = e^t$
5. **比对系数**：
   $2A = 1 \implies A = 0.5$
6. **最终通解**：
   $$y(t) = c_1 e^t + c_2 t e^t + 0.5 t^2 e^t$$

---

### 例题 5：综合终极 BOSS 题 (多项式指数冲突 + 初值问题)
**题目**：解 $y'' - 2y' + y = te^t + 4$，满足 $y(0)=1, y'(0)=1$
**解析**：
1. **解齐次方程**：
   同例题 4，$r=1$ (重根)。齐次解 $y_c = c_1 e^t + c_2 t e^t$。
2. **假设特解 $Y_p$** (分两部分)：
   * 对于 $g_1(t) = te^t$：正常多项式加指数，原本应猜 $(At+B)e^t$。但是 $e^t$ 的根是 $r=1$，发生了**重根冲突**！必须整体乘以 $t^2$。修正为 $(At^3 + Bt^2)e^t$。
   * 对于 $g_2(t) = 4$：特征根 $0$ **无冲突**，猜 $C$。
   综合猜想：$Y_p = A t^3 e^t + B t^2 e^t + C$
