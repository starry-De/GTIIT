# 常微分方程 (ODE) 第五讲：核心考点纯净版笔记

本讲开始处理更普遍的二阶线性齐次方程：$y'' + p(t)y' + q(t)y = 0$。这里的 $p(t)$ 和 $q(t)$ 可以是变量。我们将学习如何判断解的有效性，以及两种寻找新解的神奇方法。

---

## 一、 朗斯基行列式 (Wronskian) 与 基础解系

**1. 核心概念：什么是基础解系？**
在二阶线性齐次方程中，如果两个解 $y_1(t)$ 和 $y_2(t)$ 是**线性无关**的（即它们不成比例），它们就能构成一个“基础解系”。此时，方程的所有解都可以表示为它俩的线性组合：$y(t) = c_1y_1(t) + c_2y_2(t)$。

**2. 检验工具：朗斯基行列式 (Wronskian)**
我们怎么在数学上严谨地判断两个解是不是线性无关呢？数学家发明了 Wronskian：
$$W[y_1, y_2](t) = y_1(t)y_2'(t) - y_1'(t)y_2(t)$$
*(其实就是行列式 $\begin{vmatrix} y_1 & y_2 \\ y_1' & y_2' \end{vmatrix}$ 的展开)*。

**定理 (解的终极质检员)**：
只要在区间内存在某个点 $t_0$，使得 **$W(t_0) \neq 0$**，那么 $y_1$ 和 $y_2$ 就是线性无关的，它们构成基础解系！

---

## 二、 阿贝尔定理 (Abel's Theorem) - 【必考计算题】

阿贝尔定理极其神奇：它告诉我们，**就算我们完全解不出这个微分方程，我们也照样能求出它解的 Wronskian！**

**1. 定理公式**
对于标准方程 **$y'' + p(t)y' + q(t)y = 0$**，它的 Wronskian 必定满足：
$$W(t) = C e^{-\int p(t)dt}$$
*(其中 $C$ 是一个取决于初始解的常数)。*
由此可见，Wronskian 要么恒为 0（当 $C=0$ 时），要么永远不为 0。

---

#### 公式推导：为什么它长得像一阶方程的解？

这个公式之所以长得像一阶线性常微分方程的求根公式，是因为 **Wronskian 本身就满足一个一阶线性齐次微分方程**。推导过程如下：

**第一步：写出 Wronskian 及其导数**
已知 $W(t) = \begin{vmatrix} y_1 & y_2 \\ y_1' & y_2' \end{vmatrix} = y_1 y_2' - y_2 y_1'$
对其求导，应用乘积求导法则：
$$W' = (y_1' y_2' + y_1 y_2'') - (y_2' y_1' + y_2 y_1'')$$
中间的两项 $y_1' y_2'$ 相互抵消，得到：
$$W' = y_1 y_2'' - y_2 y_1''$$

**第二步：利用原方程替换二阶导数**
因为 $y_1$ 和 $y_2$ 都是原方程 $y'' + p(t)y' + q(t)y = 0$ 的解，所以满足：
$$y_1'' = -p(t)y_1' - q(t)y_1$$
$$y_2'' = -p(t)y_2' - q(t)y_2$$
将它们代入到 $W'$ 的等式中：
$$W' = y_1(-p(t)y_2' - q(t)y_2) - y_2(-p(t)y_1' - q(t)y_1)$$

**第三步：化简消项**
展开括号后你会发现，**包含 $q(t)$ 的项被神奇地抵消了**：
$$W' = -p(t)y_1 y_2' - q(t)y_1 y_2 + p(t)y_2 y_1' + q(t)y_1 y_2$$
提取公因式 $-p(t)$：
$$W' = -p(t)(y_1 y_2' - y_2 y_1')$$
括号里的部分刚好就是 $W(t)$ 本身！所以我们得到了一个完美的一阶微分方程：
$$W' + p(t)W = 0$$

解这个一阶方程（分离变量法 $\frac{dW}{W} = -p(t)dt$ 并两边积分），结果自然就是阿贝尔定理的公式：$W(t) = C e^{-\int p(t)dt}$。


#### 定理背后的物理与直观意义

1. **非黑即白的独立性**：它为“基础解系”提供了坚实的理论保障。只要在一个点上两个解是线性独立的（Wronskian 不为0），它们在整个区间上就永远线性独立。
2. **与 $q(t)$ 毫无关系**：在弹簧振子模型 $y'' + py' + qy = 0$ 中，$p(t)$ 代表阻尼（摩擦），$q(t)$ 代表弹簧恢复力。阿贝尔定理说明，Wronskian（在相空间中代表面积体积）的变化**只取决于阻尼 $p(t)$**，和弹簧的劲度系数 $q(t)$ 完全无关！如果系统无阻尼（$p(t)=0$），Wronskian 就是一个常数（相体积守恒）。

**2. 经典例题详细解析 (警惕致命易错点！)**
**题目**：已知方程 $ty'' + 2y' + te^t y = 0$ 的两个解满足 $W(1) = 2$，求 $W(5)$。
**解析**：
* **【致命易错点】**：千万不能直接把 $p(t)$ 当成 2！公式要求 $y''$ 的系数必须是 1。
* **Step 1：化为标准形**。方程两边同除以 $t$：
    $$y'' + \frac{2}{t}y' + e^t y = 0$$
    此时，真正的 $p(t) = \frac{2}{t}$。
* **Step 2：套用阿贝尔公式**。
    $$W(t) = C e^{-\int \frac{2}{t} dt} = C e^{-2\ln|t|} = C e^{\ln(t^{-2})} = C t^{-2} = \frac{C}{t^2}$$
* **Step 3：代入已知条件求 $C$**。
    已知 $W(1) = 2$，代入得 $\frac{C}{1^2} = 2 \implies C = 2$。
    所以 $W(t) = \frac{2}{t^2}$。
* **Step 4：计算目标值**。
    $W(5) = \frac{2}{5^2} = \frac{2}{25} = 0.08$。

## 三、 降阶法 (Reduction of Order)

**核心思想**：“我知道了一个解，求你给我另一个解”。
当题目白送了你一个解 $y_1(t)$，你需要找第二个线性无关的解 $y_2(t)$ 时，我们可以**猜测 $y_2(t) = v(t)y_1(t)$**。将它代入原方程后，奇迹会发生：包含 $v$ 的项会全部消掉，只剩下 $v''$ 和 $v'$，从而把一个二阶方程“降级”成一阶方程。

**例题解析**
**题目**：已知 $y_1(t) = t^{-1}$ 是 $2t^2 y'' + 3ty' - y = 0 \ (t>0)$ 的一个解，求基础解系。
**解析**：
1.  **设新解**：令 $y = v t^{-1}$。
2.  **求导准备代入**：
    $y' = v' t^{-1} - v t^{-2}$
    $y'' = v'' t^{-1} - v' t^{-2} - v' t^{-2} + 2v t^{-3} = v'' t^{-1} - 2v' t^{-2} + 2v t^{-3}$
3.  **代入原方程并化简**：
    $2t^2(v'' t^{-1} - 2v' t^{-2} + 2v t^{-3}) + 3t(v' t^{-1} - v t^{-2}) - (v t^{-1}) = 0$
    展开合并：
    $(2t)v'' + (-4 + 3)v' + (4t^{-1} - 3t^{-1} - t^{-1})v = 0$
    发现最后含有 $v$ 的项系数刚好是 $0$！方程降阶为：
    $$2t v'' - v' = 0$$
4.  **令 $u = v'$，解一阶方程**：
    $2t u' - u = 0 \implies \frac{du}{u} = \frac{1}{2t} dt \implies \ln|u| = \frac{1}{2}\ln t \implies u = t^{1/2}$
5.  **积分求 $v$，再求 $y_2$**：
    既然 $v' = u = t^{1/2}$，则 $v = \frac{2}{3}t^{3/2}$。
    所以 $y_2 = v \cdot y_1 = (\frac{2}{3}t^{3/2}) \cdot t^{-1} = \frac{2}{3}t^{1/2}$。（常数系数 $\frac{2}{3}$ 可以忽略，因为基础解系只看函数形态）。
**最终基础解系**：$\{t^{-1}, \ t^{1/2}\}$。

## 四、 欧拉方程 (Cauchy-Euler Equation)

这是一种极为特殊且常考的变系数方程，特征是**变量的幂次与求导的阶数完全匹配**。

**1. 标准形式**
$$ax^2 y'' + bx y' + cy = 0 \quad (x>0)$$

**2. 万能解法：代入 $y = x^r$**
不要去死记硬背带 $\alpha, \beta$ 的公式！做欧拉方程最简单、最不容易出错的方法是**直接假设 $y = x^r$**（类似于常系数方程猜 $y = e^{rt}$）。

* $y = x^r$
* $y' = r x^{r-1}$
* $y'' = r(r-1)x^{r-2}$

将这三个式子代入原方程，所有的 $x^2 \cdot x^{r-2}$, $x \cdot x^{r-1}$ 都会统一变成 $x^r$ 并被约掉，直接得到一个关于 $r$ 的一元二次方程（**特征方程**）：
$$ar(r-1) + br + c = 0$$

**3. 三种情况的通解 (注意自变量变了！)**
解出 $r$ 后，分三种情况（与第四讲极度相似，只是把 $e^{rt}$ 换成了 $x^r$，把 $t$ 换成了 $\ln x$）：

* **情况 1：两个相异实根 $r_1, r_2$**
    $$y(x) = c_1 x^{r_1} + c_2 x^{r_2}$$
* **情况 2：唯一重实根 $r$** (注意补的是 $\ln x$ 而不是 $x$)
    $$y(x) = c_1 x^r + c_2 x^r \ln x$$
* **情况 3：共轭复数根 $\lambda \pm \mu i$**
    $$y(x) = x^\lambda [c_1 \cos(\mu \ln x) + c_2 \sin(\mu \ln x)]$$

**例题验证** (用欧拉方法秒杀刚刚降阶法的那道题)
**题目**：$2x^2 y'' + 3x y' - y = 0$
**解析**：
代入 $y=x^r, y'=rx^{r-1}, y''=r(r-1)x^{r-2}$：
$$2x^2 [r(r-1)x^{r-2}] + 3x [rx^{r-1}] - x^r = 0$$
提取 $x^r$ 并约掉：
$$2r(r-1) + 3r - 1 = 0 \implies 2r^2 + r - 1 = 0$$
因式分解 $(2r - 1)(r + 1) = 0$，解得 $r_1 = \frac{1}{2}, r_2 = -1$。
**通解**：$y(x) = c_1 x^{1/2} + c_2 x^{-1}$。（与降阶法算出的结果完美一致！）
