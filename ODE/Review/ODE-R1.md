# 常微分方程 (ODE) 第一讲：核心考点精简复习笔记

## 一、 可分离变量方程 (Separable Differential Equations)

**1. 识别形式**
方程可以写成变量分离的乘积形式：
$$y' = f(t)g(y)$$

**2. 必杀求解步骤 (防丢分)**
* **Step 1：寻找“漏网之鱼”（常数解）**。令 $g(y) = 0$，求出所有的常数根 $y = \alpha$。这些直接就是原方程的解！（很多人在此丢分）
* **Step 2：分离变量**。将含 $y$ 的项移到左边，含 $t$ 的项移到右边（假设 $g(y) \neq 0$）：
    $$\frac{1}{g(y)} dy = f(t) dt$$
* **Step 3：两边积分**。
    $$\int \frac{1}{g(y)} dy = \int f(t) dt + C$$
* **Step 4：代入初值求特解**。如果题目给了 $y(t_0) = y_0$，将值代入求出常数 $C$。
    * *避坑指南*：如果有开平方操作（如解得 $y^2 = ...$ 得到 $y = \pm\sqrt{...}$），**必须**将初值代入验证，决定到底取正号还是负号！

## 二、 自治方程 (Autonomous Equations)

**1. 识别形式**
导数仅与未知函数 $y$ 有关，与独立变量（通常是时间 $t$）无关：
$$y' = f(y)$$
*(例如 Logistic 模型：$y' = r(1-\frac{y}{K})y$)*

**2. 平衡解 (Equilibrium Solutions)**
令 $y' = 0$（即 $f(y) = 0$）求出的常数解。在物理意义上，表示系统在这个状态下不再随时间变化（导数为0，斜率为0）。

## 三、 【核心重点】相线 (Phase Line) 怎么画与稳定性判定

画相线本质上就是在一维数轴上进行“导数正负号的图解分析”，这部分极易出大题或画图题。

**1. 手撕相线的 4 个标准步骤：**
* **第一步：画纵轴**。在纸上画一条垂直向上的直线，这条线代表状态变量 $y$。
* **第二步：标平衡点**。解出 $f(y) = 0$ 的所有根（例如 $y=0, y=2$），在纵轴上对应位置画**实心黑圆点**。这几个平衡点会把你的这根线切成几个大区间。
* **第三步：测试区间符号（定方向）**。
    * 在被切开的每个区间里，**随便挑一个好算的测试数字**，代入原方程右侧的 $f(y)$ 计算。
    * 如果算出来 $f(y) > 0$（说明 $y'$ 是正的，函数在涨），就在该区间画一个**向上**的箭头 $\uparrow$。
    * 如果算出来 $f(y) < 0$（说明 $y'$ 是负的，函数在跌），就在该区间画一个**向下**的箭头 $\downarrow$。
* **第四步：看箭头判稳定性（看图说话）**。
    根据平衡点上下方箭头的走向，直接写出结论：
    * **👉 渐近稳定 (Asymptotically Stable)**：
        上下箭头都**指向**这个点（上方 $\downarrow$，下方 $\uparrow$）。
        *形象理解：像个漏斗底，数据稍微偏离一点也会被周围的趋势
```text
       y 轴（相线）
           ^
           |
           |  ↑  (y' > 0, 向上递增)
           |
 y = 2  ---●--- (平衡点)
           |
           |  ↓  (y' < 0, 向下递减)
           |
 y = 0  ---●--- (平衡点)
           |
           |  ↑  (y' > 0, 向上递增)
           |
```
