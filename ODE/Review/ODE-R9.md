# 常微分方程 (ODE) 第九讲：级数解法纯净版笔记

当我们遇到 $P(x)y'' + Q(x)y' + R(x)y = 0$ 且 $P, Q, R$ 都是多项式时，我们可以通过将解展开为**幂级数 (Power Series)** 来求解。

---

## 一、 幂级数基础与比值审敛法 (Ratio Test)

**1. 幂级数定义**：围绕点 $x_0$ 展开的无穷级数形式为 $\sum_{n=0}^{\infty} a_n(x-x_0)^n$。

**2. 比值审敛法 (检验收敛性的神器)**：
对于级数 $\sum b_n$，计算极限 $L = \lim_{n \to \infty} \left| \frac{b_{n+1}}{b_n} \right|$：
* 如果 $L < 1$：级数绝对收敛。
* 如果 $L > 1$：级数发散。
* 如果 $L = 1$：无法判断（需单独检验端点）。

**【幻灯片 例 1】：求 $\sum_{n=1}^{\infty} (-1)^{n+1}n(x-2)^n$ 绝对收敛的 $x$ 取值范围。**
**详细解答**：
设 $b_n = (-1)^{n+1}n(x-2)^n$。
计算比值极限 $L$：
$$L = \lim_{n \to \infty} \left| \frac{(-1)^{n+2}(n+1)(x-2)^{n+1}}{(-1)^{n+1}n(x-2)^n} \right|$$
化简绝对值内的式子（$(-1)$ 的幂次被绝对值消去）：
$$L = \lim_{n \to \infty} \frac{n+1}{n} |x-2| = |x-2| \lim_{n \to \infty} \left( 1 + \frac{1}{n} \right) = |x-2| \cdot 1 = |x-2|$$
要使级数绝对收敛，必须满足 $L < 1$，即：
$$|x-2| < 1 \implies -1 < x-2 < 1 \implies 1 < x < 3$$
**结论**：该级数在开区间 $(1, 3)$ 内绝对收敛，收敛半径 $\rho = 1$。

## 二、 幂级数的求导与递推原理 (核心套路)

如果 $y(x) = \sum_{n=0}^{\infty} a_n x^n = a_0 + a_1 x + a_2 x^2 + a_3 x^3 + \dots$
对其逐项求导，注意**求导后起始下标的变化**（因为常数项求导为0）：
$$y'(x) = \sum_{n=1}^{\infty} a_n n x^{n-1}$$
$$y''(x) = \sum_{n=2}^{\infty} a_n n(n-1) x^{n-2}$$

### 【定理 5.3 (常点展开法则)】
对于 $P(x)y'' + Q(x)y' + R(x)y = 0$，如果 $P(x_0) \neq 0$（说明 $x_0$ 是一个安全的“常点”），那么一般解必定可以写成：
$$y = \sum_{n=0}^{\infty} a_n(x-x_0)^n = a_0 y_0(x) + a_1 y_1(x)$$
其中 $a_0$ 对应初值 $y(x_0)$，$a_1$ 对应初值 $y'(x_0)$。

## 三、 幻灯片例题超详细解析 (绝不跳步)

做级数解法题的核心思想：**统一 $x$ 的幂次，统一求和符号的起始下标，合并同类项，让总系数等于 0，得到递推公式。**

### 【例题 2】：求 $y'' + y = 0$ 的级数解
**详细解析**：
1. 设解为 $y = \sum_{n=0}^{\infty} a_n x^n$，则 $y'' = \sum_{n=2}^{\infty} a_n n(n-1)x^{n-2}$。
2. 为了与 $y$ 的 $x^n$ 统一幂次，我们对 $y''$ 进行**下标平移法则**。令 $k = n-2$，则 $n = k+2$。当 $n=2$ 时，$k=0$。
   $$y'' = \sum_{k=0}^{\infty} a_{k+2}(k+2)(k+1)x^k$$
   （为了方便，我们统一把求和指标都改写回 $n$）
   $$y'' = \sum_{n=0}^{\infty} a_{n+2}(n+2)(n+1)x^n$$
3. 代入原方程 $y'' + y = 0$：
   $$\sum_{n=0}^{\infty} a_{n+2}(n+2)(n+1)x^n + \sum_{n=0}^{\infty} a_n x^n = 0$$
   合并成一个求和：
   $$\sum_{n=0}^{\infty} \big[ a_{n+2}(n+2)(n+1) + a_n \big] x^n = 0$$
4. 既然整个多项式恒为0，说明每一项的系数都必须为0。得出**递推关系式**：
   $$a_{n+2} = -\frac{a_n}{(n+2)(n+1)}$$
5. 开始递推推导：
   * **偶数项 (由 $a_0$ 决定)**：
     $n=0: \quad a_2 = -\frac{a_0}{2 \times 1} = -\frac{a_0}{2!}$
     $n=2: \quad a_4 = -\frac{a_2}{4 \times 3} = -\frac{-a_0/2!}{4 \times 3} = \frac{a_0}{4!}$
     以此类推：$a_{2k} = (-1)^k \frac{a_0}{(2k)!}$
   * **奇数项 (由 $a_1$ 决定)**：
     $n=1: \quad a_3 = -\frac{a_1}{3 \times 2} = -\frac{a_1}{3!}$
     $n=3: \quad a_5 = -\frac{a_3}{5 \times 4} = -\frac{-a_1/3!}{5 \times 4} = \frac{a_1}{5!}$
     以此类推：$a_{2k+1} = (-1)^k \frac{a_1}{(2k+1)!}$
6. **结论**：
   $$y(x) = a_0 \sum_{k=0}^{\infty} \frac{(-1)^k}{(2k)!} x^{2k} + a_1 \sum_{k=0}^{\infty} \frac{(-1)^k}{(2k+1)!} x^{2k+1}$$
   *(这就是极其著名的泰勒展开式，它完美证明了方程的解正是 $y(x) = a_0\cos(x) + a_1\sin(x)$)*

### 【例题 3】：泰勒级数法直接求系数
**题目**：已知 $(1+x^2)y'' + 2xy' + 4x^2y = 0$, $y(0)=0, y'(0)=1$。设 $y = a_0 + a_1x + a_2x^2 + a_3x^3 + \dots$，求 $a_0, a_1, a_2, a_3$。
**详细解析**：
根据泰勒公式，$a_n = \frac{y^{(n)}(0)}{n!}$。
1. **求 $a_0, a_1$**：
   $a_0 = y(0) = 0$
   $a_1 = y'(0) / 1! = 1 / 1 = 1$
2. **求 $a_2$**：
   把 $x=0$ 代入原微分方程：
   $(1+0)y''(0) + 0 \cdot y'(0) + 0 \cdot y(0) = 0 \implies y''(0) = 0$
   所以 $a_2 = y''(0) / 2! = 0 / 2 = 0$
3. **求 $a_3$**：
   我们需要求出 $y'''(0)$。对方程两边同时对 $x$ 求一次导（使用乘积求导法则）：
   $[(1+x^2)y'''] + [2x y''] + [2x y'' + 2y'] + [4x^2 y' + 8xy] = 0$
   化简：
   $(1+x^2)y''' + 4xy'' + (2+4x^2)y' + 8xy = 0$
   把 $x=0$ 代入上述新方程：
   $(1+0)y'''(0) + 0 + 2y'(0) + 0 = 0 \implies y'''(0) + 2(1) = 0 \implies y'''(0) = -2$
   所以 $a_3 = y'''(0) / 3! = -2 / 6 = -1/3$
**结论**：$a_0 = 0, \ a_1 = 1, \ a_2 = 0, \ a_3 = -1/3$。

### 【例题 4】：完整解初值问题
**题目**：解 $y'' + xy' + 2y = 0$, $y(0)=4, y'(0)=-1$。
**详细解析**：
已知 $a_0 = y(0) = 4, a_1 = y'(0) = -1$。
设解为级数形式代入原式：
$$y'' = \sum_{n=2}^{\infty} a_n n(n-1)x^{n-2} \xrightarrow{\text{平移 } k=n-2} \sum_{k=0}^{\infty} a_{k+2}(k+2)(k+1)x^k$$
$$xy' = x\sum_{n=1}^{\infty} a_n n x^{n-1} = \sum_{n=1}^{\infty} a_n n x^n \xrightarrow{\text{重命名 } k=n} \sum_{k=1}^{\infty} a_k k x^k$$
*(注意：对于 $xy'$ 的求和，当 $k=0$ 时，项 $a_0(0)x^0 = 0$，所以我们可以安全地把求和下限从 $k=1$ 改成 $k=0$，方便统一合并)*。
$$2y = 2\sum_{k=0}^{\infty} a_k x^k = \sum_{k=0}^{\infty} 2a_k x^k$$

把三个式子加起来等于0：
$$\sum_{k=0}^{\infty} \big[ a_{k+2}(k+2)(k+1) + a_k k + 2a_k \big] x^k = 0$$
令大括号内的系数为0：
$a_{k+2}(k+2)(k+1) + a_k(k+2) = 0$
约去非零的 $(k+2)$，得到**递推公式**：
$$a_{k+2} = -\frac{a_k}{k+1}$$

由于给定了 $a_0 = 4, a_1 = -1$，我们只需向后推导：
* $k=0: \quad a_2 = -a_0 / 1 = -4$
* $k=2: \quad a_4 = -a_2 / 3 = -(-4) / 3 = 4/3$
* $k=1: \quad a_3 = -a_1 / 2 = -(-1) / 2 = 1/2$
* $k=3: \quad a_5 = -a_3 / 4 = -(1/2) / 4 = -1/8$
**结论（展开到前五次项）**：
$$y(x) = 4 - x - 4x^2 + \frac{1}{2}x^3 + \frac{4}{3}x^4 - \frac{1}{8}x^5 + \dots$$

### 【例题 5】：极具戏剧性的截断级数（变为多项式）
**题目**：解 $y'' - 2xy' + 10y = 0$, $y(0)=0, y'(0)=3$，并求 $y(1/2)$ 的值。
**详细解析**：
同样代入各项：
$$y'' = \sum_{k=0}^{\infty} a_{k+2}(k+2)(k+1)x^k$$
$$-2xy' = -2x \sum_{k=1}^{\infty} a_k k x^{k-1} = \sum_{k=0}^{\infty} (-2a_k k) x^k$$
$$10y = \sum_{k=0}^{\infty} 10a_k x^k$$
合并提取递推公式：
$$a_{k+2}(k+2)(k+1) - 2a_k k + 10a_k = 0 \implies a_{k+2}(k+2)(k+1) = (2k-10)a_k$$
**递推公式为**：
$$a_{k+2} = \frac{2k - 10}{(k+2)(k+1)} a_k$$

根据初值：$a_0 = 0, a_1 = 3$。
因为 $a_0 = 0$，所以所有偶数项 $a_2, a_4, a_6 \dots$ 全都等于 0！
我们只算奇数项：
* $k=1: \quad a_3 = \frac{2(1)-10}{3 \times 2} a_1 = \frac{-8}{6} \times 3 = -4$
* $k=3: \quad a_5 = \frac{2(3)-10}{5 \times 4} a_3 = \frac{-4}{20} \times (-4) = \frac{4}{5} = 0.8$
* $k=5: \quad a_7 = \frac{2(5)-10}{7 \times 6} a_5 = \frac{0}{42} a_5 = 0$ ！！！

**奇迹发生了**！因为 $a_7 = 0$，后续所有的奇数项 $a_9, a_{11} \dots$ 全部等于 0。这个无限的级数被截断成了一个精确的有限多项式：
$$y(x) = 3x - 4x^3 + \frac{4}{5}x^5$$

最后代入 $x = 1/2$：
$$y(1/2) = 3(0.5) - 4(0.5)^3 + 0.8(0.5)^5$$
$$y(1/2) = 1.5 - 4(0.125) + 0.8(0.03125) = 1.5 - 0.5 + 0.025 = 1.025$$
**结论**：$y(1/2) = 1.025$。
