### 一、 一阶线性微分方程 (First Order Linear Equations)

#### 1. 核心知识点与标准形式
一阶线性微分方程通常可以写成以下**标准形式 (Standard form)**：
$$y^{\prime} + p(x)y = r(x)$$

**核心思想**：观察等式左边 $y^{\prime} + p(x)y$，它看起来非常接近某种“乘积的导数”展开后的样子，但缺少了关键的一块。为了凑成完全导数，我们需要给等式两边同乘一个神奇的函数 $\mu(x)$，这个函数就被称为**积分因子 (Integrating factor)**。

#### 2. 定理与完整推导
**定理**：对于标准形式 $y^{\prime} + p(x)y = r(x)$，其积分因子为 $\mu(x) = e^{\int p(x)dx}$。

**推导证明**：
1. 我们希望方程两边同乘 $\mu(x)$ 后，左边能变成 $(\mu(x)y)^{\prime}$。
2. 展开期望的导数：$(\mu(x)y)^{\prime} = \mu(x)y^{\prime} + \mu^{\prime}(x)y$。
3. 将原方程同乘 $\mu(x)$：$\mu(x)y^{\prime} + \mu(x)p(x)y = \mu(x)r(x)$。
4. 对比第2步和第3步的左式，我们必须让：
   $$\mu^{\prime}(x)y = \mu(x)p(x)y \implies \mu^{\prime}(x) = \mu(x)p(x)$$
5. 这是一个可分离变量方程，分离并求解 $\mu(x)$：
   $$\frac{d\mu}{\mu} = p(x)dx$$
   $$\int \frac{1}{\mu} d\mu = \int p(x)dx$$
   $$\ln|\mu(x)| = \int p(x)dx \implies \mu(x) = e^{\int p(x)dx}$$

#### 3. 详细例题解析
**例题**：求微分方程 $y^{\prime} - 2y = e^{2x}$ 的所有解，并求满足初始条件 $y(0) = 3$ 的特解。

**解答步骤**：
* **Step 1：确认标准形式并找 $p(x)$**。方程已是标准形式，$p(x) = -2$，$r(x) = e^{2x}$。
* **Step 2：计算积分因子**。
  $$\mu(x) = e^{\int -2 dx} = e^{-2x}$$
* **Step 3：方程两边同乘 $\mu(x)$**。
  $$e^{-2x}y^{\prime} - 2e^{-2x}y = e^{-2x}e^{2x}$$
  等式左边必然可以合并为 $(\mu(x)y)^{\prime}$，右边化简为 1：
  $$(e^{-2x}y)^{\prime} = 1$$
* **Step 4：两边积分，求出通解**。
  $$e^{-2x}y = \int 1 dx = x + C$$
  $$y(x) = (x + C)e^{2x}$$
* **Step 5：代入初始条件** $y(0) = 3$。
  $$3 = (0 + C)e^{0} \implies C = 3$$
  **最终特解**：$y(x) = (x + 3)e^{2x}$。

### 二、 恰当方程 (Exact Differential Equations)

#### 1. 核心知识点与定义
如果一个一阶微分方程可以写成：
$$M(x,y) + N(x,y)y^{\prime} = 0$$
（或者写成对称的微分形式 $M(x,y)dx + N(x,y)dy = 0$）

**定义**：如果存在一个二元函数 $\psi(x,y)$，使得 $\frac{\partial\psi}{\partial x}(x,y) = M(x,y)$ 并且 $\frac{\partial\psi}{\partial y}(x,y) = N(x,y)$，我们就称这个微分方程是**恰当的 (Exact)**。此时，原方程就变成了 $\frac{d}{dx}\psi(x,y) = 0$，它的隐式解直接就是 $\psi(x,y) = C$。

#### 2. 直观理解：寻找隐藏的“山”与全微分
这段纯数学的定义非常抽象，要直观地理解它，最好的方法是用**“爬山”与“地形图”**来打个比方。

想象你站在一片连绵起伏的山脉中，空间中任意一点的位置坐标是 $(x, y)$。
* 设 $\psi(x,y)$ 是这片山脉的**高度函数（地形图）**。只要输入坐标 $(x, y)$，它就告诉你当前的海拔是多少。
* $\frac{\partial \psi}{\partial x}$ 就是你纯粹向**正东方向**跨一步时，感受到的**坡度**（高度变化率）。
* $\frac{\partial \psi}{\partial y}$ 就是你纯粹向**正北方向**跨一步时，感受到的**坡度**。

现在，我们来看你的微分方程：$M(x,y)dx + N(x,y)dy = 0$。在这个比喻中：
* $M(x,y)$ 相当于给定的**东西向坡度**。
* $N(x,y)$ 相当于给定的**南北向坡度**。
* $dx$ 和 $dy$ 是你在 $x$ 方向和 $y$ 方向迈出的**微小步伐**。

**为什么等于 0？（等高线的秘密）**
在微积分中，如果你朝任意方向走了一小步（横向走 $dx$，纵向走 $dy$），你的**总高度变化（全微分 $d\psi$）** 等于两个方向的高度变化之和：
$$d\psi = \frac{\partial \psi}{\partial x}dx + \frac{\partial \psi}{\partial y}dy$$

恰当方程的定义说，$\frac{\partial \psi}{\partial x} = M$，并且 $\frac{\partial \psi}{\partial y} = N$。所以上面的式子就变成了：
$$d\psi = Mdx + Ndy$$

而你的微分方程恰好规定了 $Mdx + Ndy = 0$。这意味着 **$d\psi = 0$（高度总变化为 0）**！这个微分方程描述的是这样一种运动轨迹——**无论你走到哪里，你的海拔高度都不允许发生变化**。你在绕着山腰走平地！

在地图上，高度始终不变的线就是**等高线 (Contour line)**。既然函数的变化量为 0，说明这个函数本身没有发生改变，自然就是一个**常数**。这就是为什么它的解直接就是 $\psi(x,y) = C$。

**为什么叫“恰当 (Exact)”？**
如果随便给两个毫无关联的函数 $M$ 和 $N$，在现实中可能**根本不存在**这样一座山能同时满足这两种坡度。只有当 $M$ 和 $N$ 配合得“**恰到好处**”，它们确确实实来源于同一座真实的、三维世界里的“山” $\psi(x,y)$ 时，方程才是恰当的。求解恰当方程的本质，就是当“地形复原大师”，把那座隐藏的“山” $\psi(x,y)$ 的全貌拼凑还原出来。

#### 3. 定理 2.6.1 (判断恰当性的充要条件)
**定理**：方程 $M(x,y) + N(x,y)y^{\prime} = 0$ 是恰当方程，**当且仅当**满足：
$$\frac{\partial M}{\partial y}(x,y) = \frac{\partial N}{\partial x}(x,y)$$
*(注：这其实运用了偏导数中混合偏导相等的克莱罗定理 $\psi_{xy} = \psi_{yx}$)*。

#### 4. 详细例题解析与常数合并细节
**例题**：解微分方程 $2x + y^{2} + 2xyy^{\prime} = 0$。

**解答步骤**：
* **Step 1：识别 $M$ 和 $N$，并验证恰当性**。
  $$M = 2x + y^{2}, \quad N = 2xy$$
  求偏导：$M_y = 2y$，$N_x = 2y$。因为 $M_y = N_x$，方程是恰当的。
* **Step 2：根据 $\psi_x = M$ 积分找 $\psi$**。
  $$\psi(x,y) = \int (2x + y^{2}) dx = x^{2} + xy^{2} + h(y)$$
  *(注意：对 $x$ 积分时，常数项是一个关于 $y$ 的函数 $h(y)$)*。
* **Step 3：利用 $\psi_y = N$ 确定 $h(y)$**。
  对上面求出的 $\psi$ 关于 $y$ 求偏导：
  $$\psi_y = 2xy + h^{\prime}(y)$$
  令其等于 $N$：
  $$2xy + h^{\prime}(y) = 2xy \implies h^{\prime}(y) = 0 \implies h(y) = C_1$$
  此时我们得出了完整的函数：$\psi(x,y) = x^2 + xy^2 + C_1$。
* **Step 4：写出最终解（常数的“融合”）**。
  恰当方程的通解严格定义是 $\psi(x,y) = C_2$。代入得到：
  $$x^2 + xy^2 + C_1 = C_2$$
  把常数移到右边：$x^2 + xy^2 = C_2 - C_1$。由于一个任意常数减去另一个任意常数依然是一个任意常数，我们直接把 $(C_2 - C_1)$ 整体打包，重新命名为一个新的常数 $C$。
  **所以最终通解为**：
  $$x^2 + xy^2 = C$$
  *(做题技巧：在 Step 3 算出 $h'(y) = 0$ 时，我们通常直接取 $h(y) = 0$，不去写 $C_1$，到了 Step 4 直接在等号右边补上统一的 $C$ 即可避免绕晕。)*

### 三、 积分因子法化为恰当方程

有时候，一个方程刚开始并不恰当（$M_y \neq N_x$）。但我们可以通过给它乘以一个多变量的积分因子 $\mu(x,y)$，使得新方程 $[\mu(x,y)M(x,y)] + [\mu(x,y)N(x,y)]y^{\prime} = 0$ 变成恰当方程。

寻找这个 $\mu$ 的通用方程非常难解，但有**两种特殊且常考**的情形：

#### 定理：寻找单变量积分因子
1. **只依赖于 $x$ 的情况**：
   如果 $\frac{M_y(x,y) - N_x(x,y)}{N(x,y)} = f(x)$（结果仅与 $x$ 有关），则积分因子为：
   $$\mu(x) = e^{\int f(x)dx}$$
2. **只依赖于 $y$ 的情况**：
   如果 $\frac{N_x(x,y) - M_y(x,y)}{M(x,y)} = g(y)$（结果仅与 $y$ 有关），则积分因子为：
   $$\mu(y) = e^{\int g(y)dy}$$

#### 详细例题解析
**例题**：求 $(3xy + y^{2}) + (x^{2} + xy)y^{\prime} = 0$ 过点 $(1,0)$ 的特解。

**解答步骤**：
* **Step 1：验证是否恰当**。
  $M = 3xy + y^{2}, N = x^{2} + xy$。
  $M_y = 3x + 2y, N_x = 2x + y$。$M_y \neq N_x$，不恰当。
* **Step 2：寻找积分因子**。
  尝试套用公式 1：
  $$\frac{M_y - N_x}{N} = \frac{(3x + 2y) - (2x + y)}{x^{2} + xy} = \frac{x + y}{x(x + y)} = \frac{1}{x}$$
  这是一个只依赖 $x$ 的函数 $f(x)$。因此积分因子为：
  $$\mu(x) = e^{\int \frac{1}{x} dx} = e^{\ln x} = x$$
* **Step 3：乘以积分因子化为恰当方程求解**。
  方程同乘 $x$：
  $$(3x^{2}y + xy^{2}) + (x^{3} + x^{2}y)y^{\prime} = 0$$
  现在它是恰当的了。设解为 $\psi(x,y) = C$：
  $\psi_y = N = x^{3} + x^{2}y \implies \psi = \int(x^{3} + x^{2}y)dy = x^{3}y + \frac{1}{2}x^{2}y^{2} + g(x)$。
  对 $x$ 求偏导验证 $M$：$\psi_x = 3x^{2}y + xy^{2} + g^{\prime}(x) = M \implies g^{\prime}(x) = 0$。
  所以通解为 $x^{3}y + \frac{1}{2}x^{2}y^{2} = C$。
* **Step 4：代入初始条件** $y(1) = 0$。
  $(1)^{3}(0) + \frac{1}{2}(1)^{2}(0)^{2} = C \implies C = 0$。
  **最终特解**：$x^{3}y + \frac{1}{2}x^{2}y^{2} = 0$（可以化简为 $y(x^{3} + \frac{1}{2}x^{2}y) = 0$）。
