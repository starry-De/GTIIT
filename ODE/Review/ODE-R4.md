# 常微分方程 (ODE) 第四讲：核心考点精简复习笔记

本讲正式进入进阶领域——**二阶线性微分方程**。重点聚焦于最基础也是最核心的情况：**常系数齐次方程**。这部分内容在期末考试中必定是计算题的重头戏。

---

## 一、 核心概念：二阶线性常系数齐次方程

**1. 标准形式**
一般二阶线性方程形式为 $y^{\prime\prime}+p(t)y^{\prime}+q(t)y=g(t)$ 。当 $g(t)=0$ 时，称为齐次方程 。
我们主要研究常系数齐次方程：
$$ay^{\prime\prime} + by^{\prime} + cy = 0$$ 
* **二阶**：出现了二阶导数 $y^{\prime\prime}$。
* **常系数**：$a, b, c$ 都是给定的常数 。
* **齐次**：等式右边为 $0$ 。

**2. 初值问题 (IVP)**
因为方程被求了两次导，如果要确定最终解里的常数，需要**两个初始条件**：
通常给定初始位置 $y(t_0) = y_0$ 和初始速度 $y^{\prime}(t_0) = y_0^{\prime}$ 。

**3. 基本解组 (Fundamental Solutions)**
对于方程 $ay^{\prime\prime} + by^{\prime} + cy = 0$，如果能找到两个**线性无关**的解 $y_1(t)$ 和 $y_2(t)$（即 $\alpha y_1(t) + \beta y_2(t) = 0$ 仅当 $\alpha=\beta=0$ 时成立 ），那么通解 (General Solution) 就是它们的线性组合：
$$y(t) = c_1 y_1(t) + c_2 y_2(t)$$ 

---

## 二、 核心解法：特征方程 (Characteristic Equation)

解常系数齐次方程的核心思想是“猜”指数形式的解。将其代入后，可转化为代数方程。

**特征方程定义：**
将 $y^{\prime\prime}$ 替换为 $r^2$，$y^{\prime}$ 替换为 $r$，$y$ 替换为 $1$，得到一元二次方程：
$$ar^2 + br + c = 0$$ 

根据求根公式 $\Delta = b^2 - 4ac$ 的不同，分为三种情况：

**情况 1：有两个不相等的实数根 ($\Delta > 0$)** 
假设特征方程有两个不同的实根 $r_1$ 和 $r_2$ 。
* **基本解**：$y_1 = e^{r_1 t}, \quad y_2 = e^{r_2 t}$
* **通解**：
  $$y(t) = c_1 e^{r_1 t} + c_2 e^{r_2 t}$$ 

**情况 2：有一个重实根 ($\Delta = 0$)** 
假设特征方程有两个相同的实数根 $r_1 = r_2 = r$ 。
为了构造第二个线性无关的解，数学上证明了需要给它乘上一个 $t$ 。
* **基本解**：$y_1 = e^{r_1 t}, \quad y_2 = t e^{r_1 t}$
* **通解**：
  $$y(t) = c_1 e^{r_1 t} + c_2 t e^{r_1 t}$$ 
*(易错点提醒：考试时千万别忘了第二项里的那个 $t$！)*

**情况 3：有一对共轭复数根 ($\Delta < 0$)** 
假设解出的复数根为 $r = \lambda \pm i\mu$ （其中 $\lambda$ 是实部，$\mu$ 是虚部 ）。
借助欧拉公式 $e^{i\theta} = \cos(\theta) + i\sin(\theta)$ ，可以把复数指数转化为实数的三角函数 。
* **基本解**：$y_1 = e^{\lambda t}\cos(\mu t), \quad y_2 = e^{\lambda t}\sin(\mu t)$ 
* **通解**：
  $$y(t) = c_1 e^{\lambda t}\cos(\mu t) + c_2 e^{\lambda t}\sin(\mu t)$$ 
  或者提取公因式写成：
  $$y(t) = e^{\lambda t} (c_1\cos(\mu t) + c_2\sin(\mu t))$$

## 三、 幻灯片例题详细解答 (实战演练)

**例题 1 (对应情况 1)**
**题目**：求解 $y^{\prime\prime} - y = 0$，初始条件 $y(0) = 2, \ y^{\prime}(0) = -1$ 。
**解析**：
1.  写出特征方程：$r^2 - 1 = 0 \implies r = \pm 1$。
2.  两根不同，写出通解：$y(t) = c_1 e^t + c_2 e^{-t}$。
3.  对通解求导：$y^{\prime}(t) = c_1 e^t - c_2 e^{-t}$。
4.  代入初值：
    $y(0) = c_1 e^0 + c_2 e^0 = c_1 + c_2 = 2$
    $y^{\prime}(0) = c_1 e^0 - c_2 e^0 = c_1 - c_2 = -1$
5.  解方程组：两式相加得 $2c_1 = 1 \implies c_1 = 0.5$；进而得出 $c_2 = 1.5$。
6.  **最终解**：$y(t) = 0.5e^t + 1.5e^{-t}$

**例题 2 (对应情况 2)**
**题目**：求解 $y^{\prime\prime} + 4y^{\prime} + 4y = 0$ 。
**解析**：
1.  写出特征方程：$r^2 + 4r + 4 = 0$。
2.  因式分解：$(r+2)^2 = 0$，解得唯一重根 $r = -2$。
3.  套用情况2的公式。
4.  **通解**：$y(t) = c_1 e^{-2t} + c_2 t e^{-2t}$。

**例题 3 (对应情况 3)**
**题目**：求解 $16y^{\prime\prime} - 8y^{\prime} + 145y = 0$。*(注：PPT原文写成了 $16y^{\prime\prime}-8y+145y=0$ ，此处修正为标准的中间项含导数形式)*。
**解析**：
1.  写出特征方程：$16r^2 - 8r + 145 = 0$。
2.  用求根公式解 $r$：
    $$r = \frac{-(-8) \pm \sqrt{(-8)^2 - 4(16)(145)}}{2(16)} = \frac{8 \pm \sqrt{64 - 9280}}{32} = \frac{8 \pm \sqrt{-9216}}{32}$$
    因为 $\sqrt{-9216} = 96i$，所以：
    $$r = \frac{8 \pm 96i}{32} = \frac{1}{4} \pm 3i$$
3.  这里实部 $\lambda = \frac{1}{4}$，虚部 $\mu = 3$。
4.  套用情况3的公式。
5.  **通解**：$y(t) = e^{\frac{1}{4}t} (c_1\cos(3t) + c_2\sin(3t))$。

## 四、 深入理解：不同系数对系统行为的影响

二阶常系数齐次微分方程在物理上通常描述的是**振动系统**（例如弹簧振子或RLC电路）。$a, b, c$ 的取值直接决定了系统的阻尼情况，对应特征根的三种情况：
* **情况 1 (两个实根)**：**过阻尼 (Overdamped)**。阻力太大，系统不会震荡，而是缓慢回到平衡位置。
* **情况 2 (重实根)**：**临界阻尼 (Critically damped)**。系统以最快的速度回到平衡位置且不产生震荡。
* **情况 3 (复数根)**：**欠阻尼 (Underdamped)**。阻力较小，系统会围绕平衡位置来回震荡，振幅随时间被实部 $\lambda$ 放大或缩小。
