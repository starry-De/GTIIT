# 常微分方程 (ODE) 第三讲：核心考点与理论精讲笔记

本讲内容标志着我们从“纯技巧计算”迈向了“系统理论分析”。核心包括三大板块：一阶线性方程的**常数变易法**（万能解法）、**存在唯一性定理**（解的质检报告），以及可以伪装成线性方程的**伯努利方程**。

---

## 一、 常数变易法 (Variation of Parameters)

除了积分因子法，这是求解一阶线性非齐次方程 $y^{\prime} + p(x)y = r(x)$ 的另一把瑞士军刀。并且它是后续求解高阶微分方程的基础。

### 1. 必杀操作三步曲
* **Step 1：解“齐次方程”摸底**
    抹掉右边的干扰项 $r(x)$，先解 $y^{\prime} + p(x)y = 0$。分离变量求出一个基础解，记为 $u(x) = e^{-\int p(x)dx}$。
* **Step 2：假设解并代入（魔法发生处）**
    假设原非齐次方程的解为 **$y(x) = C(x)u(x)$**。
    对其求导得 $y^{\prime} = C^{\prime}u + Cu^{\prime}$，代入原方程后，含有 $C(x)$ 的项会**绝对完美地相互抵消**，方程瞬间坍缩为：
    $$C^{\prime}(x)u(x) = r(x)$$
* **Step 3：积分收尾**
    解出 $C^{\prime}(x) = \frac{r(x)}{u(x)}$，两边积分求出 $C(x)$（记得加常数 $C_1$），再乘回 $u(x)$ 得到最终通解。

### 2. 【核心原理】知其所以然（为什么常数能变？）
不要把它当成数学家的拼凑技巧，它有着极强的**物理直觉**：
* **齐次解 $u(x)$ 是系统的“固有基因”**：比如弹簧在没有外力时的自然衰减规律。这个骨架是固定的。
* **常数 $C$ 是系统的“初始振幅”**：如果没有外力干扰，振幅永远锁定。
* **非齐次项 $r(x)$ 是“外部干预”**：外界持续施加力量，**不会改变系统的底层基因 $u(x)$**，但会迫使原本固定的振幅 $C$ 变成一个随时间流动的函数 $C(x)$。代入后抵消掉的部分，就是系统自身完美内部消耗的证明；剩下的 $C^{\prime}u = r(x)$，单纯在描述外力是如何一滴滴改变振幅的。

## 二、 存在唯一性定理 (解的“质检报告”)

算题之前，数学家必须知道解存不存在、是不是唯一。我们可以用**“铺设火车轨道”**的直觉来理解。

### 1. 线性方程：宽容的“高速公路”
针对标准形式：$y^{\prime} + p(t)y = r(t), \quad y(t_0) = y_0$
* **定理要求**：只要 $p(t)$ 和 $r(t)$ 在包含出发点 $t_0$ 的区间内是**连续的**。
* **结论**：在这个区间内，解**一定存在且绝对唯一**（全局有效）。
* **做题套路**：找茬。算出 $p(t)$ 和 $r(t)$ 什么时候分母为 0 或对数小于 0，把这些“坏点”在数轴上抠掉。包含 $t_0$ 的那一段完好无损的开区间，就是最大安全区间。

### 2. 非线性方程：苛刻的“越野泥潭”
针对形式：$y^{\prime} = f(t,y), \quad y(t_0) = y_0$
* **定理要求**：在点 $(t_0, y_0)$ 附近，不仅要求图纸本身 **$f(t,y)$ 是连续的**，还严苛地要求图纸的偏导数 **$\frac{\partial f}{\partial y}$ 也必须是连续的**。
* **结论**：在 $t_0$ 附近的一小段区间内，解存在且唯一（局部有效）。

### 3. 【核心考点】唯一性破灭的瞬间（经典反例）
**考题**：$y^{\prime} = \sqrt{y}, \quad y(0) = 0$
* **破绽**：$f(t,y) = \sqrt{y}$ 在 $y=0$ 处连续（存在解）。但是，偏导数 $\frac{\partial f}{\partial y} = \frac{1}{2\sqrt{y}}$ 在 $y=0$ 处**分母为 0，瞬间发散爆炸！**
* **后果（轨道分叉）**：因为偏导数（斜率的变化率）爆炸，导致同一个出发点 $(0,0)$ 居然铺出了两条不同的轨道：
    1.  常数解：$y(t) = 0$
    2.  抛物线解：$y(t) = \frac{1}{4}t^2 \quad (t \ge 0)$
    这就是典型的“满足存在性，但不满足唯一性”的灾难现场。

## 三、 伯努利方程 (Bernoulli Equation)

有些方程长得像非线性，但可以通过一套固定操作“降维打击”成线性方程。

**1. 识别标准面孔**
$$y^{\prime} + p(x)y = q(x)y^n \quad (n \ge 2)$$
特点：左边很乖，是线性的；右边非要多乘一个高次幂 $y^n$ 捣乱。

**2. 求解武器库**
面对伯努利方程，你有两种完全等效的武器可供选择：

* **武器 A：经典换元法 (专业对口，速度快)**
    1.  方程两边同除以捣乱的 $y^n$，得到 $y^{-n}y^{\prime} + p(x)y^{1-n} = q(x)$。
    2.  背诵并使用**核心换元公式： $z = y^{1-n}$**。
    3.  [[[[[[[[[[[上面]]]]]]]]]]]
    4.  两边求导得 $z^{\prime} = (1-n)y^{-n}y^{\prime}$。
    5.  代入原方程，必定会化简为一个完美的关于 $z$ 的一阶线性方程：$z^{\prime} + (1-n)p(x)z = (1-n)q(x)$。
    6.  用积分因子法求出 $z$，最后取 $\frac{1}{1-n}$ 次方换回 $y$。

* **武器 B：常数变易法 (无脑万能，免背公式)**
    1.  无视右边的 $q(x)y^n$，先解左边的齐次方程 $y^{\prime} + p(x)y = 0$，得到基础解 $u(x)$。
    2.  假设通解为 $y(x) = C(x)u(x)$ 并代回原伯努利方程。
    3.  经过完美的魔法抵消后，方程会变成 $C^{\prime}u = q(x)[Cu]^n$。
    4.  移项后得到 $\frac{C^{\prime}}{C^n} = q(x)u^{n-1}$。这**直接就是一个可分离变量方程**！
    5.  积分求出 $C(x)$，装配回 $y(x)$ 即得最终解。
