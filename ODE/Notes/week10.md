## 1. 拉普拉斯变换的哲学与定义

### 核心哲学：空间换元与解题战场转移
拉普拉斯变换的核心思想是**变换的哲学 (Philosophy of Transforms)**。当在**时域（时空宇宙，变量为 $t$）**面对复杂的微积分方程难以下手时，通过积分变换将问题“传送”到**频域（复频率宇宙，变量为 $s$）**。
* **时域的微积分运算** $\longrightarrow$ 转换为 **频域的代数加减乘除**。
* 在频域解出代数方程后，通过**逆变换**传送回时域，直接获得原方程的特解。

### 数学定义
设 $f(t)$ 是定义在 $[0, \infty)$ 上的函数，其**拉普拉斯变换**（记作 $\mathcal{L}\{f(t)\}$ 或 $F(s)$）定义为广义积分：

$$\mathcal{L}\{f(t)\} = F(s) = \int_{0}^{\infty} e^{-st} f(t) \, dt$$

其中 $s$ 为复变量（初学阶段可视为正实数）。该变换存在的充要条件是右侧广义积分在 $s$ 的某区域内收敛。

### 核心推导技巧（以基础函数为例）
**常数函数 $f(t) = 1$：**
$$\mathcal{L}\{1\} = \int_{0}^{\infty} e^{-st} (1) \, dt = \left[ -\frac{1}{s}e^{-st} \right]_{0}^{\infty} = 0 - \left(-\frac{1}{s}\right) = \frac{1}{s} \quad (s > 0)$$

**指数函数 $f(t) = e^{at}$：**
$$\mathcal{L}\{e^{at}\} = \int_{0}^{\infty} e^{-st} e^{at} \, dt = \int_{0}^{\infty} e^{-(s-a)t} \, dt = \left[ -\frac{1}{s-a}e^{-(s-a)t} \right]_{0}^{\infty} = \frac{1}{s-a} \quad (s > a)$$

## 2. 变换存在的充分条件 (定理 6.1.2)

并非所有函数都能进行拉普拉斯变换（如 $e^{t^2}$ 增长过快导致积分发散）。定理 6.1.2 规定了积分收敛的**充分条件**：

### 定理内容
若函数 $f(t)$ 满足以下两个条件：
1. **分段连续 (Piecewise continuous)：** 在任何有限区间 $0 \le t \le b$ 上， $f(t)$ 只有有限个第一类间断点。
2. **指数阶 (Exponential order)：** 存在正实常数 $K, a, M$，使得当 $t \ge M$ 时，满足：
   $$|f(t)| \le K e^{at}$$

**结论：** 则 $\mathcal{L}\{f(t)\} = F(s)$ 在区域 $s > a$ 上必然存在且绝对收敛。

> **直观理解：** $e^{-st}$ 是一个强大的“衰减因子/驯兽师”。只要原函数 $f(t)$ 的增长速度不超过某个指数函数，我们总能选取足够大的 $s$，使得积分强行收敛。

## 3. 核心性质与代数降维魔法

### 线性性质 (Linearity)
拉普拉斯变换是**线性算子**，满足可加性和齐次性。
$$\mathcal{L}\{a f(t) + b g(t)\} = a \mathcal{L}\{f(t)\} + b \mathcal{L}\{g(t)\}$$

### 导数的拉普拉斯变换 (降维核心)
这是将微积分转化为代数方程的关键。

* **一阶导数公式：**
  $$\mathcal{L}\{f'(t)\} = sF(s) - f(0)$$
* **二阶导数公式：**
  $$\mathcal{L}\{f''(t)\} = s^2F(s) - s f(0) - f'(0)$$

#### 核心逻辑推导过程 (基于分部积分法)
设 $\mathcal{L}\{f'(t)\} = \int_{0}^{\infty} e^{-st} f'(t) \, dt$。
1. 令 $dv = f'(t) \, dt \implies v = f(t)$
2. 令 $u = e^{-st} \implies du = -s e^{-st} \, dt$
3. 带入分部积分公式 $\int u \, dv = uv - \int v \, du$：
   $$\int_{0}^{\infty} e^{-st} f'(t) \, dt = \left[ e^{-st} f(t) \right]_{0}^{\infty} - \int_{0}^{\infty} f(t) \left(-s e^{-st}\right) \, dt$$
4. 边界值计算得 $0 - f(0) = -f(0)$；剩余积分项计算得 $s F(s)$。
5. 整合结果得出：$\mathcal{L}\{f'(t)\} = sF(s) - f(0)$。

## 4. 分段函数与单位阶跃函数

### 数学定义
单位阶跃函数 $u_c(t)$ (也作 $H(t-c)$) 代表在 $t=c$ 时刻被按下的“开关”：
$$u_c(t) = \begin{cases} 0, & 0 \le t < c \\ 1, & t \ge c \end{cases} \quad (c \ge 0)$$

### 阶跃函数的拉普拉斯变换
$$\mathcal{L}\{u_c(t)\} = \int_{0}^{\infty} u_c(t) e^{-st} \, dt = \int_{c}^{\infty} e^{-st} \, dt = \left[ -\frac{1}{s} e^{-st} \right]_{c}^{\infty} = \frac{e^{-sc}}{s} \quad (s > 0)$$

## 5. 第二平移定理 (时间延迟定理 6.3.1)

本定理建立了“时域内的延迟信号”与“频域内乘衰减因子”的映射。

### 定理公式
若 $\mathcal{L}\{f(t)\} = F(s)$ 存在，且 $c > 0$ 为常数，则正向变换为：
$$\mathcal{L}\{u_c(t) f(t-c)\} = e^{-cs} F(s)$$

**逆变换形式（解题最常用）：**
$$\mathcal{L}^{-1}\{e^{-cs} F(s)\} = u_c(t) f(t-c)$$

> **物理意义：** $u_c(t)f(t-c)$ 表示系统在 $c$ 秒之前绝对死寂，到了 $c$ 秒，突然按照原有的规律 $f(t)$ 开始运行。看到频域有 $e^{-cs}$，逆变换时务必把所有 $t$ 替换成 $t-c$，并套上开关 $u_c(t)$。

## 6. 微积分降维打击实战案例

### 🎯 求解初始值微分方程
方程：$$y'(t) - 2y(t) = e^{3t} \quad \text{初始条件: } y(0) = 2$$

#### 第一步：正变换（全部传送到 $s$ 域）
$$[sY(s) - y(0)] - 2Y(s) = \frac{1}{s-3}$$
代入初始值 $y(0) = 2$：
$$sY(s) - 2 - 2Y(s) = \frac{1}{s-3}$$

#### 第二步：纯代数移项（解出 $Y(s)$）
$$(s - 2)Y(s) = \frac{1}{s-3} + 2 = \frac{2s - 5}{s-3}$$
$$Y(s) = \frac{2s - 5}{(s-2)(s-3)}$$

#### 第三步：逆变换（部分分式拆分法回传时域）
$$\frac{2s - 5}{(s-2)(s-3)} = \frac{A}{s-2} + \frac{B}{s-3}$$
通过代入极点解得 $A = 1, B = 1$，所以：
$$Y(s) = \frac{1}{s-2} + \frac{1}{s-3}$$
查表逆变换，直接输出最终特解：
$$y(t) = e^{2t} + e^{3t}$$

## 7. 全套常用拉普拉斯变换对照表

### 表 1：基础函数对照表 (时域 $\leftrightarrow$ 频域)

| 时域原函数 $f(t)$ ($t \ge 0$) | 频域象函数 $F(s)$ | 特征记忆 |
| :--- | :--- | :--- |
| $1$ | $\frac{1}{s}$ | 最基础的积木 |
| $t$ | $\frac{1}{s^2}$ | 幂次比时域多 1 阶 |
| $t^n$ ($n \in \mathbb{N}^+$) | $\frac{n!}{s^{n+1}}$ | 分子阶乘，分母幂次加 1 |
| $e^{at}$ | $\frac{1}{s-a}$ | 带有极点 $s=a$ |
| $\sin(\omega t)$ | $\frac{\omega}{s^2 + \omega^2}$ | 分母平方**和**，分子常数 $\omega$ |
| $\cos(\omega t)$ | $\frac{s}{s^2 + \omega^2}$ | 分母平方**和**，分子变量 $s$ |
| $\sinh(\omega t)$ | $\frac{\omega}{s^2 - \omega^2}$ | 分母平方**差**，分子常数 $\omega$ |
| $\cosh(\omega t)$ | $\frac{s}{s^2 - \omega^2}$ | 分母平方**差**，分子变量 $s$ |
| $\delta(t)$ (脉冲冲激) | $1$ | 变换后是个常数 |
| $u_c(t)$ (单位阶跃) | $\frac{e^{-sc}}{s}$ | 时间延迟开关 |

### 表 2：核心运算性质表 (语法变形规则)

| 性质名称 | 时域操作 $f(t)$ | 频域操作 $F(s)$ | 应用场景 |
| :--- | :--- | :--- | :--- |
| **线性性质** | $a f_1(t) + b f_2(t)$ | $a F_1(s) + b F_2(s)$ | 多项式拆分 |
| **第一平移 (s域平移)** | $e^{at} f(t)$ | $F(s-a)$ | 乘以指数衰减，s全体替换为(s-a) |

| **一阶微分** | $f'(t)$ | $sF(s) - f(0)$ | 降维核心魔法 |
| **时域积分** | $\int_{0}^{t} f(\tau) \, d\tau$ | $\frac{F(s)}{s}$ | 时域积分 = 频域除以 $s$ |
