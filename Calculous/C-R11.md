# 微积分 2M 期末复习讲义 (Lecture 21 & 22)

## 一、 格林定理 (Green's Theorem)

格林定理是微积分基本定理在二维空间的推广，它将**沿着封闭曲线的线积分**与**该曲线所包围区域的二重积分**完美联系在了一起。

### 1. 定理内容与核心公式
> **格林定理 (Green's Theorem)**
> 设 $D$ 是平面上的一个区域，其边界 $\Gamma = \partial D$ 是一条（或几条）**分段光滑、无自交（Simple）、闭合（Closed）**的曲线，且取**正向（Positively oriented，即逆时针方向，或者说人沿着曲线走，区域 $D$ 始终在左手边）**。
> 若向量场 $\vec{F}(x,y) = P(x,y)\hat{i} + Q(x,y)\hat{j}$ 在 $D$ 及其边界上具有连续的一阶偏导数（$C^1$），则：
> $$\oint_{\Gamma} (P dx + Q dy) = \iint_D \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) dxdy$$

**做题直觉**：如果你在期末考中遇到一个沿着**闭合曲线**的线积分，且直接积分极其复杂（比如含有无法积分的 $e^{x^2}$ 或高次项），**一定要立刻想到用格林定理将其转化为二重积分！**

### 2. 利用格林定理求面积
如果我们在格林定理中巧妙地选取 $P$ 和 $Q$，使得 $\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} = 1$，那么右边的二重积分就变成了区域 $D$ 的面积！
常用的面积公式变形：
$$\text{Area}(D) = \oint_{\Gamma} x dy = -\oint_{\Gamma} y dx = \frac{1}{2} \oint_{\Gamma} (x dy - y dx)$$

## 二、 保守向量场 (Conservative Vector Fields)

在物理学中，做功与路径无关的力场（如重力场、静电场）就是保守场。

### 1. 三大等价条件 (The Big Equivalence Theorem)
设 $\vec{F}(x,y) = P\hat{i} + Q\hat{j}$ 是区域 $D$ 上的连续向量场。以下三个条件是**完全等价**的：

1. **环路积分为零**：对 $D$ 内的任意闭合曲线 $\Gamma$，都有 $\oint_{\Gamma} \vec{F} \cdot d\vec{r} = 0$。（这是保守场的严谨定义）。
2. **路径无关 (Path Independent)**：对于 $D$ 内任意两点 $A$ 和 $B$，积分 $\int_A^B \vec{F} \cdot d\vec{r}$ 的值仅仅取决于起点和终点，而与连接它们的具体路径无关。
3. **存在势函数 (Potential Function)**：存在一个标量函数 $\phi(x,y)$，使得 $\vec{F} = \nabla\phi$（即 $P = \frac{\partial \phi}{\partial x}$, $Q = \frac{\partial \phi}{\partial y}$）。此时，线积分可以直接用“牛顿-莱布尼茨公式”计算：$\int_A^B \vec{F} \cdot d\vec{r} = \phi(B) - \phi(A)$。

> **证明：(1) 与 (2) 的等价性推导**
> * **从 (1) 推 (2)**：设 $A, B$ 之间有两条不同路径 $\Gamma_1$ 和 $\Gamma_2$。我们让物体沿 $\Gamma_1$ 从 $A$ 到 $B$，再沿逆方向 $-\Gamma_2$ 从 $B$ 回到 $A$。这就构成了一个闭合回路 $\Gamma = \Gamma_1 \cup (-\Gamma_2)$。
>   根据条件(1)，$\oint_{\Gamma} \vec{F} \cdot d\vec{r} = 0$。
>   展开即：$\int_{\Gamma_1} \vec{F} \cdot d\vec{r} + \int_{-\Gamma_2} \vec{F} \cdot d\vec{r} = 0 \implies \int_{\Gamma_1} \vec{F} \cdot d\vec{r} - \int_{\Gamma_2} \vec{F} \cdot d\vec{r} = 0$。
>   所以 $\int_{\Gamma_1} \vec{F} \cdot d\vec{r} = \int_{\Gamma_2} \vec{F} \cdot d\vec{r}$，这就证明了路径无关。
> * **反之从 (2) 推 (1)** 的思路几乎完全相同。

### 2. 旋度检验法 (The Cross-Partial Test)
在单连通区域（没有“洞”的区域）上，判定向量场 $\vec{F} = (P,Q)$ 是否保守有一个极其简单的代数判定：
**如果是保守场 $\implies \frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y}$。** *(原理很简单：因为 $P = \phi_x, Q = \phi_y$，根据克莱罗定理混合偏导数相等，$\phi_{xy} = \phi_{yx}$，即 $P_y = Q_x$)*。

## 三、 参数化曲面与切平面 (Parametrized Surfaces)

之前我们学了如何用参数 $t$ 描述一维的“曲线”（$\vec{r}(t)$），现在我们用两个参数 $u, v$ 描述二维的“曲面”。

### 1. 曲面的参数化表示
$$\vec{\Sigma}(u,v) = \big( x(u,v), y(u,v), z(u,v) \big)$$
常见的参数化技巧：
* **圆柱面 ($x^2+y^2=R^2$)**：$\vec{\Sigma}(\theta, z) = (R\cos\theta, R\sin\theta, z)$
* **球面 ($x^2+y^2+z^2=R^2$)**：利用球坐标，$\vec{\Sigma}(\phi, \theta) = (R\sin\phi\cos\theta, R\sin\phi\sin\theta, R\cos\phi)$
* **显式函数曲面 ($z = f(x,y)$)**：最简单的办法是令 $u=x, v=y$，则 $\vec{\Sigma}(x,y) = (x, y, f(x,y))$。

### 2. 曲面的法向量与切平面
固定 $v = v_0$，$\vec{\Sigma}(u, v_0)$ 就是曲面上的一条网格曲线。对其求导得到切向量 $\vec{r}_u$。同理有另一条曲线的切向量 $\vec{r}_v$。
* **两个基本切向量**：
  $\vec{r}_u = \left( \frac{\partial x}{\partial u}, \frac{\partial y}{\partial u}, \frac{\partial z}{\partial u} \right)$
  $\vec{r}_v = \left( \frac{\partial x}{\partial v}, \frac{\partial y}{\partial v}, \frac{\partial z}{\partial v} \right)$
* **法向量 (Normal Vector)**：两者作叉积即可得到垂直于曲面的法向量！
  $$\vec{n} = \vec{r}_u \times \vec{r}_v$$
* **切平面方程**：在点 $\vec{r}_0 = \vec{\Sigma}(u_0, v_0)$ 处，利用点法式方程：
  $\vec{n} \cdot \big( \vec{R} - \vec{r}_0 \big) = 0$ （展开即 $A(x-x_0) + B(y-y_0) + C(z-z_0) = 0$）

## 四、 重点例题详细解析

**【例题 1：格林定理化简繁琐线积分】**
**题目**：计算线积分 $\oint_C (e^{x^2} - y^3) dx + (x^3 + \sin(y^2)) dy$，其中 $C$ 是原点为圆心，半径为 $2$ 的圆 $x^2+y^2=4$，逆时针方向。
**解析**：
1. 这个积分直接算根本积不出 $e^{x^2}$ 和 $\sin(y^2)$，必须用格林定理。
2. 识别 $P = e^{x^2} - y^3$ 和 $Q = x^3 + \sin(y^2)$。
3. 计算偏导数：
   $\frac{\partial Q}{\partial x} = 3x^2$
   $\frac{\partial P}{\partial y} = -3y^2$
4. 运用格林定理：
   $\oint_C Pdx + Qdy = \iint_D (\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}) dA = \iint_D (3x^2 - (-3y^2)) dA = \iint_D 3(x^2+y^2) dA$。
5. 利用极坐标计算二重积分（区域 $D$ 是半径为 2 的圆盘）：
   $= \int_0^{2\pi} \int_0^2 3(r^2) \cdot r dr d\theta = \int_0^{2\pi} d\theta \cdot \int_0^2 3r^3 dr = 2\pi \cdot \left[ \frac{3}{4}r^4 \right]_0^2 = 2\pi \cdot 12 = 24\pi$。

**【例题 2：寻找势函数并求做功】**
**题目**：判断向量场 $\vec{F} = (2xy^3, 3x^2y^2 + \cos y)$ 是否保守？如果保守，求出其势函数 $\phi(x,y)$，并计算从点 $(0,0)$ 移动到点 $(1, \pi)$ 所做的功。
**解析**：
1. **检验保守性**：
   $P = 2xy^3 \implies P_y = 6xy^2$。
   $Q = 3x^2y^2 + \cos y \implies Q_x = 6xy^2$。
   因为 $P_y = Q_x$ 且定义域没有“洞”，故 $\vec{F}$ 是保守场。
2. **寻找势函数 $\phi$**（偏积分法）：
   已知 $\phi_x = 2xy^3$。对 $x$ 积分得到：$\phi(x,y) = \int 2xy^3 dx = x^2y^3 + g(y)$ （注意常数项变为了关于 $y$ 的未知函数）。
   对刚才得到的 $\phi$ 求 $y$ 的偏导：$\phi_y = 3x^2y^2 + g'(y)$。
   将它与已知的 $Q$ 对比：$3x^2y^2 + g'(y) = 3x^2y^2 + \cos y \implies g'(y) = \cos y$。
   积分得 $g(y) = \sin y$。所以势函数 $\phi(x,y) = x^2y^3 + \sin y$。
3. **计算做功**（利用基本定理）：
   $W = \int_{(0,0)}^{(1,\pi)} \vec{F} \cdot d\vec{r} = \phi(1, \pi) - \phi(0,0)$。
   $\phi(1, \pi) = (1)^2(\pi)^3 + \sin\pi = \pi^3 + 0 = \pi^3$。
   $\phi(0,0) = 0 + 0 = 0$。
   做功 $W = \pi^3$。

**【例题 3：求参数曲面的切平面】**
**题目**：考虑参数曲面 $\vec{\Sigma}(u,v) = (u\cos v, u\sin v, u^2)$。求在点 $(u_0, v_0) = (1, \pi/2)$ 处的切平面方程。
**解析**：
1. **计算该点在三维空间中的坐标**：
   $\vec{r}_0 = \vec{\Sigma}(1, \pi/2) = (1\cos(\pi/2), 1\sin(\pi/2), 1^2) = (0, 1, 1)$。
2. **求两个偏导切向量**：
   $\vec{r}_u = (\cos v, \sin v, 2u)$。在 $(1, \pi/2)$ 处为 $(0, 1, 2)$。
   $\vec{r}_v = (-u\sin v, u\cos v, 0)$。在 $(1, \pi/2)$ 处为 $(-1, 0, 0)$。
3. **求法向量 $\vec{n}$**（叉积）：
   $\vec{n} = \vec{r}_u \times \vec{r}_v = \begin{vmatrix} \hat{i} & \hat{j} & \hat{k} \\ 0 & 1 & 2 \\ -1 & 0 & 0 \end{vmatrix} = (0, -2, 1)$。
4. **写出切平面方程**：
   $0(x-0) - 2(y-1) + 1(z-1) = 0 \implies -2y + z + 1 = 0$。
