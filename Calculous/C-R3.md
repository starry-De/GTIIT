# 微积分 2M 期末复习讲义 (Lecture 5 & 6)

## 一、 $\mathbb{R}^n$ 空间的拓扑基础 (Topology in $\mathbb{R}^n$)

### 1. 距离与度量空间
在 $\mathbb{R}^n$ 空间中，两点 $\vec{x}$ 和 $\vec{y}$ 之间的距离定义为：
$d(\vec{x}, \vec{y}) = \sqrt{(x_1-y_1)^2 + (x_2-y_2)^2 + \dots + (x_n-y_n)^2}$
距离函数满足四个公理：(1) 自己到自己距离为0；(2) 非负性及同一性；(3) 对称性 $d(x,y)=d(y,x)$；(4) 三角不等式 $d(x,y) + d(y,z) \ge d(x,z)$。

### 2. 邻域与集合分类
* **开球 (Open Ball)**：$B(\vec{x}^0, R) = \{\vec{x} \in \mathbb{R}^n : d(\vec{x}^0, \vec{x}) < R\}$。也称为 $\vec{x}^0$ 的 $\epsilon$-邻域。
* **闭球 (Closed Ball)**：$\overline{B}(\vec{x}^0, R) = \{\vec{x} \in \mathbb{R}^n : d(\vec{x}^0, \vec{x}) \le R\}$。
* **内点 (Interior Point)**：若存在一个以 $\vec{x}^0$ 为中心的开球完全包含在集合 $A$ 内，则称 $\vec{x}^0$ 为 $A$ 的内点。
* **边界点 (Boundary Point)**：若 $\vec{x}^0$ 的任何 $\epsilon$-邻域都既包含 $A$ 中的点，又包含不在 $A$ 中的点，则称为边界点。（注：边界点不一定属于集合 $A$）。
* **开集 (Open Set)**：集合内的所有点都是内点。
* **闭集 (Closed Set)**：集合包含了其所有的边界点。
* **有界集 (Bounded Set)**：若集合能被包含在某个有限半径的开球内，则称其有界。

### 3. 多维空间中的数列 (Sequences)
* **收敛性**：数列 $\vec{x}^n \to \vec{L}$ 的充要条件是其**各个分量**都收敛于 $\vec{L}$ 的对应分量（即 $x_1^n \to L_1, x_2^n \to L_2, \dots$）。
* **Bolzano-Weierstrass 定理**：$\mathbb{R}^n$ 中的任何**有界数列**都必有一个收敛的子数列。

## 二、 多元函数与几何表示 (Functions and Graphs)

### 1. 图像 (Graph)
对于二元函数 $z = f(x,y)$，其定义域 $D \subset \mathbb{R}^2$，其图像存在于 $\mathbb{R}^3$ 空间中，表示为曲面 $\{(x, y, f(x,y)) : (x,y) \in D\}$。

### 2. 等值线与等值面 (Level Curves & Surfaces)
为了在低维空间中可视化高维函数，我们引入“降维打击”：
* **等值线 (Level Curves)**：对于 $z = f(x,y)$，令 $f(x,y) = C$（常数）所得到的平面曲线。
  * *例子*：$f(x,y) = x^2 + y^2 = C$ 是一簇同心圆。
  * *例子*：$f(x,y) = xy = C$ 是一簇双曲线（该函数图像为马鞍面 Saddle）。
* **等值面 (Level Surfaces)**：对于三元函数 $w = f(x,y,z)$（图像在无法直接想象的4维空间），令 $f(x,y,z) = C$ 在三维空间中形成曲面。
  * *例子*：$f(x,y,z) = x^2 + y^2 - z = C \implies z = x^2 + y^2 - C$，这是一簇沿 z 轴平移的抛物面。

## 三、 多元函数的极限 (Limits)

这是本阶段的**重中之重**！二元极限 $\lim_{(x,y)\to(a,b)} f(x,y) = L$ 意味着：当动点 $(x,y)$ **以任何方式（任何路径）**逼近 $(a,b)$ 时，函数值都必须逼近 $L$。

### 1. 极限存在的严谨定义 ($\epsilon-\delta$ 定义)
> $\forall \epsilon > 0, \exists \delta > 0$，使得当 $0 < \sqrt{(x-a)^2 + (y-b)^2} < \delta$ 时，都有 $|f(x,y) - L| < \epsilon$。

### 2. 证明极限存在的两大方法
* **方法一：夹逼定理 (Squeeze Theorem)**
  如果 $h(x,y) \le f(x,y) \le g(x,y)$，且两边的极限都为 $L$，则 $f(x,y)$ 的极限也为 $L$。
* **方法二：极坐标替换法 (Polar Coordinates)**
  当 $(x,y) \to (0,0)$ 时，令 $x = r\cos\theta, y = r\sin\theta$。
  > **核心定理**：如果 $f(r\cos\theta, r\sin\theta) = F(r)G(\theta)$，其中 $\lim_{r\to 0} F(r) = 0$，且 $G(\theta)$ 是**有界**的（即存在常数 $M$ 使得 $|G(\theta)| \le M$），那么 $\lim_{(x,y)\to(0,0)} f(x,y) = 0$。

### 3. 证明极限【不存在】的方法 (Path Dependency)
> **定理**：如果沿两条不同的路径趋近 $(a,b)$，得到了两个不同的极限值，则原极限**不存在 (Does Not Exist, DNE)**。
* **常用路径一**：直线路径 $y = \alpha x$（或 $y = kx$）。
* **常用路径二**：抛物线路径 $y = x^2$ 或 $x = y^2$（常用于上下次幂不平衡的情况）。

### 4. 累次极限 (Iterated Limits)
累次极限是指先对一个变量求极限，再对另一个求：$\lim_{x\to a} [\lim_{y\to b} f(x,y)]$。
* **重要结论**：如果多元整体极限（二重极限）存在，且某个累次极限也存在，那么**它们一定相等**。
* **注意**：累次极限相等**不代表**整体极限存在；整体极限存在，累次极限也可能不存在（因为单变量极限过程中可能震荡）。

## 四、 重点例题详细解析

**【例题 1：用极坐标证明极限存在】**
**题目**：证明 $\lim_{(x,y)\to(0,0)} \frac{x^2y^2}{x^2+y^2} = 0$。
**解析**：
1. 转化为极坐标：$x = r\cos\theta, y = r\sin\theta$。分母 $x^2+y^2 = r^2$。
2. 代入函数：
   $f(r\cos\theta, r\sin\theta) = \frac{(r\cos\theta)^2(r\sin\theta)^2}{r^2} = \frac{r^4\cos^2\theta\sin^2\theta}{r^2} = r^2\cos^2\theta\sin^2\theta$。
3. 拆分为 $F(r)$ 和 $G(\theta)$：令 $F(r) = r^2$，$G(\theta) = \cos^2\theta\sin^2\theta$。
4. 验证条件：显然当 $r \to 0$ 时，$F(r) \to 0$；且对于任何 $\theta$，都有 $|G(\theta)| \le 1$（有界）。
5. 结论：由极坐标定理，原极限为 0。

**【例题 2：沿不同直线路径证明极限不存在】**
**题目**：求证 $\lim_{(x,y)\to(0,0)} \frac{xy}{x^2+y^2}$ 不存在。
**解析**：
1. 选取直线路径 $y = \alpha x$ 趋近于 $(0,0)$。
2. 将 $y = \alpha x$ 代入函数：
   $f(x, \alpha x) = \frac{x(\alpha x)}{x^2 + (\alpha x)^2} = \frac{\alpha x^2}{x^2(1+\alpha^2)} = \frac{\alpha}{1+\alpha^2}$。
3. 当 $x \to 0$ 时，沿该路径的极限值为 $\frac{\alpha}{1+\alpha^2}$。
4. 结论：极限值依赖于参数 $\alpha$（即逼近的角度）。例如沿 $y=x$ ($\alpha=1$) 极限为 $1/2$；沿 $y=0$ ($\alpha=0$) 极限为 $0$。因为沿不同路径得到不同值，故原极限不存在。

**【例题 3：直线路径失效，改用抛物线路径】**
**题目**：求证 $\lim_{(x,y)\to(0,0)} \frac{x^2y}{x^4+y^2}$ 不存在。
**解析**：
1. 先试直线路径 $y = \alpha x$：
   $f(x, \alpha x) = \frac{\alpha x^3}{x^4 + \alpha^2 x^2} = \frac{\alpha x}{x^2 + \alpha^2}$。当 $x \to 0$ 时，该式极限为 0。
   （这说明沿**任何直线**趋近，极限都是 0。但我们还不能说整体极限就是 0！）
2. 试抛物线路径 $y = x^2$（目的是让分子分母的“次数”齐平）：
   代入得：$f(x, x^2) = \frac{x^2(x^2)}{x^4 + (x^2)^2} = \frac{x^4}{2x^4} = \frac{1}{2}$。
3. 结论：沿任何直线逼近极限为 0，但沿抛物线 $y=x^2$ 逼近极限为 $1/2$。结果不唯一，故原极限不存在。
